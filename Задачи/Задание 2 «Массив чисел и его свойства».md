### Что нужно сделать
Написать программу, которая:
1. Спрашивает, сколько чисел будет в массиве (от 1 до 100)
2. Создаёт массив нужного размера
3. Просит пользователя ввести эти числа
4. Находит и выводит:
   - Сумму всех чисел
   - Среднее арифметическое
   - Самое большое число
   - Самое маленькое число

### Пример работы программы
```
Сколько чисел будет в массиве? 5
Введите 5 чисел:
10 20 30 40 50

Сумма: 150
Среднее: 30
Максимум: 50
Минимум: 10
```

### Важные моменты
- Массив создаётся **динамически** через `new` (это важно!)
- Перед завершением программы память нужно освободить через `delete[]`
- Если пользователь ввёл размер меньше 1 или больше 100 — сообщить об ошибке

### Как это работает (объяснение для учителя)
```
1. Запрашиваем размер N
2. Создаём массив: int* arr = new int[N]
3. Заполняем его через цикл
4. Проходим по массиву, считаем сумму, ищем максимум/минимум
5. Освобождаем память: delete[] arr
```

### Подводные камни
- Деление на ноль при вычислении среднего (если N = 0, но мы это запретили)
- Забыть освободить память — будет утечка
- Неправильная индексация (начинаем с 1 вместо 0)
