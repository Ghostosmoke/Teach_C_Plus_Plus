### Что нужно сделать
Объединить все предыдущие задания в одну программу с меню:
1. Показать текущий массив
2. Добавить элемент в конец
3. Удалить элемент по номеру
4. Вставить элемент на любую позицию
5. Выйти из программы

### Пример работы программы
```
Текущий массив: (пусто)

Меню:
1. Показать массив
2. Добавить элемент
3. Удалить элемент
4. Вставить элемент
5. Выход

Ваш выбор: 2
Введите число: 10

Ваш выбор: 2
Введите число: 20

Ваш выбор: 2
Введите число: 30

Ваш выбор: 1
Массив: 10 20 30

Ваш выбор: 4
Какое число вставить? 15
На какую позицию? 2

Ваш выбор: 1
Массив: 10 15 20 30

Ваш выбор: 5
До свидания!
```

### Что это даёт
- Ученик видит, как работает **реальный динамический массив**
- Понимает, почему в C++ есть `std::vector` (который делает всё это автоматически)
- Учит работать с циклами, условиями, функциями
- Понимает, как управлять памятью вручную

### Варианты реализации

**Вариант А: Всё в main**
Просто, но нечитаемо. Подходит для самых начинающих.

**Вариант Б: Разбить на функции**
```
void printArray(int* arr, int size)
int* addElement(int* arr, int size, int value)
int* removeElement(int* arr, int size, int position)
int* insertElement(int* arr, int size, int value, int position)
```
Каждая функция возвращает **новый массив** (или nullptr при ошибке).

**Что лучше?** Вариант Б учит структурировать код, но сложнее для понимания. Можно начать с А, потом переделать в Б.
