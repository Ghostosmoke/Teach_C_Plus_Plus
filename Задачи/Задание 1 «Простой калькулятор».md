### Что нужно сделать
Написать программу, которая:
1. Спрашивает у пользователя два числа
2. Спрашивает, какую операцию выполнить (+, -, *, /)
3. Выводит результат

### Пример работы программы
```
Введите первое число: 10
Введите второе число: 5
Выберите операцию (+, -, *, /): *
Результат: 50
```

### Важные моменты
- Нужно проверить, что при делении второе число не равно нулю
- Если пользователь ввёл что-то неправильное (например, букву вместо числа), программа должна сообщить об ошибке

### Варианты решения

**Вариант А: через if-else**
```
Если операция == "+", то складываем
Иначе если операция == "-", то вычитаем
Иначе если операция == "*", то умножаем
Иначе если операция == "/", то делим
Иначе сообщаем, что операция неизвестна
```

**Вариант Б: через switch**
```
Переключаемся по значению операции:
  случай "+": складываем
  случай "-": вычитаем
  случай "*": умножаем
  случай "/": делим
  по умолчанию: ошибка
```

**Что лучше?** Switch читается легче, когда вариантов много. If-else гибче, если нужно проверять сложные условия.
