# Задача 1: «Создание и анализ матрицы»

### Что нужно сделать
Создать программу, которая:
1. Спрашивает у пользователя размеры матрицы (N строк, M столбцов)
2. Позволяет заполнить матрицу числами вручную
3. Выводит матрицу на экран в виде таблицы
4. Находит и выводит:
   - Сумму всех элементов
   - Максимальный и минимальный элемент
   - Количество чётных и нечётных элементов

### Пример работы программы
```
Введите количество строк: 3
Введите количество столбцов: 4

Заполните матрицу:
Строка 1: 5 8 3 12
Строка 2: 7 2 9 4
Строка 3: 6 11 1 10

Ваша матрица:
 5   8   3  12
 7   2   9   4
 6  11   1  10

Результаты анализа:
Сумма всех элементов: 78
Максимальный элемент: 12
Минимальный элемент: 1
Чётных элементов: 7
Нечётных элементов: 5
```

### Что это даёт
- Ученик понимает, как работать с **двумерными массивами**
- Осваивает **вложенные циклы** (цикл в цикле)
- Учится работать с индексами `[i][j]`
- Понимает разницу между строками и столбцами
- Видит, как обрабатывать данные в табличной структуре
- Готовится к более сложным задачам (матричные операции, игры типа "Морской бой")

### Варианты реализации

**Вариант А: Статический массив (фиксированный размер)**
```cpp
int matrix[10][10];  // максимум 10x10
int n, m;  // реальные размеры
```
Просто, но ограничивает размер матрицы.

**Вариант Б: Динамический массив**
```cpp
int** matrix = new int*[n];
for(int i = 0; i < n; i++) {
    matrix[i] = new int[m];
}
```
Сложнее, но позволяет создавать матрицы любого размера. Учит работе с указателями.

**Вариант В: Одномерный массив вместо двумерного**
```cpp
int* matrix = new int[n * m];
// доступ: matrix[i * m + j] вместо matrix[i][j]
```
Показывает, как двумерные массивы хранятся в памяти на самом деле.

### Подсказки для ученика
- Для вывода матрицы в виде таблицы используй `\t` (табуляция) между элементами
- Для поиска максимума/минимума начни с первого элемента матрицы
- Чётность проверяй через `% 2 == 0`
- Не забудь освободить память в конце программы (если используешь `new`)
