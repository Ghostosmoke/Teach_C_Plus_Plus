### Что нужно сделать
Написать программу, которая:
1. Создаёт массив из 5 чисел (заполняет пользователь)
2. Спрашивает, какое число нужно добавить
3. **Создаёт новый массив на 1 элемент больше**
4. Копирует все старые числа в новый массив
5. Добавляет новое число в конец
6. **Освобождает старый массив**
7. Выводит новый массив

### Пример работы программы
```
Введите 5 чисел:
10 20 30 40 50

Какое число добавить? 60

Новый массив: 10 20 30 40 50 60
```

### Почему это сложно
В C++ массив **фиксированного размера нельзя увеличить**. Если создали массив на 5 элементов — он таким и останется. Чтобы добавить элемент, нужно:
1. Создать **новый** массив побольше
2. Скопировать туда старые данные
3. Удалить старый массив
4. Теперь работаем с новым массивом

### Варианты решения

**Вариант А: Простое копирование через цикл**
```
1. Создаём новый массив размером N+1
2. В цикле копируем первые N элементов из старого массива
3. Добавляем новое число в позицию N (последнюю)
4. Удаляем старый массив
```

**Вариант Б: Использование функции memcpy**
```
1. Создаём новый массив размером N+1
2. Копируем старую память в новую одной командой memcpy
3. Добавляем новое число
4. Удаляем старый массив
```

**Что лучше?** Вариант А понятнее для начинающих. Вариант Б быстрее работает, но требует понимания, как устроена память.

### Подводные камни
- Забыть скопировать все элементы
- Неправильно рассчитать размер нового массива
- Удалить старый массив **до** копирования (потеряем данные)
- Удалить старый массив **дважды** (ошибка)
