### Что нужно сделать
Написать программу, которая:
1. Создаёт массив из 7 чисел
2. Спрашивает, какой **по счёту** элемент удалить (от 1 до 7)
3. Создаёт новый массив на 1 элемент меньше
4. Копирует все элементы, **пропуская** тот, который нужно удалить
5. Выводит новый массив

### Пример работы программы
```
Массив: 10 20 30 40 50 60 70
Какой элемент удалить (по номеру)? 3

Новый массив: 10 20 40 50 60 70
```

### Как это работает
```
Старый массив: [10, 20, 30, 40, 50, 60, 70]
Хотим удалить элемент номер 3 (это число 30, индекс 2)

Новый массив: [10, 20, 40, 50, 60, 70]
```

### Алгоритм словами
1. Запрашиваем номер элемента для удаления (от 1 до N)
2. Преобразуем в индекс: `index = номер - 1`
3. Создаём новый массив размером N-1
4. Копируем элементы:
   - Все элементы до `index` — как есть
   - Все элементы после `index` — со сдвигом на 1 влево
5. Удаляем старый массив

### Подводные камни
- Пользователь может ввести номер меньше 1 или больше N — нужна проверка
- Перепутать номер элемента (начинается с 1) и индекс (начинается с 0)
- При копировании пропустить элемент или скопировать дважды
