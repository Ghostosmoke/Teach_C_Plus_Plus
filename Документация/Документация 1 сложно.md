# Улучшенный калькулятор - Документация

## Что это за программа

Это улучшенная версия калькулятора, которая:
- Работает **циклически** - не завершается после одной операции
- Использует **функции** - код разбит на логические части
- Имеет **меню** - удобный выбор операций
- Поддерживает **дополнительные операции** - возведение в степень

Программа работает, пока пользователь сам не решит выйти.

## Главное отличие от простой версии

**Простая версия:**
```
Запуск → Ввод → Вычисление → Вывод → Завершение
```

**Улучшенная версия:**
```
Запуск → Цикл:
  ├── Показ меню
  ├── Выбор операции
  ├── Ввод чисел
  ├── Вычисление
  ├── Вывод результата
  └── Спросить: "Продолжить?"
       ├── Да → вернуться к началу цикла
       └── Нет → завершение
```

## Как работает программа (пошагово)

### Шаг 1: Функции - отдельные блоки кода

В отличие от простой версии, здесь код разбит на **функции**:

```cpp
double add(double a, double b) {
    return a + b;
}
```

**Что это значит:**
- Мы создали функцию с именем `add`
- Она принимает два параметра: `a` и `b` (оба типа `double`)
- Она возвращает результат типа `double`
- Внутри функции происходит сложение: `a + b`
- `return` - возвращает результат вызвавшему коду

**Зачем нужны функции?**
1. **Читаемость** - код легче понять
2. **Переиспользование** - можно вызвать функцию много раз
3. **Модульность** - можно тестировать каждую функцию отдельно
4. **Поддержка** - легче найти и исправить ошибку

### Шаг 2: Функция divide с проверкой ошибок

```cpp
double divide(double a, double b, bool &success) {
    if (b == 0) {
        success = false;
        return 0;
    }
    success = true;
    return a / b;
}
```

**Что здесь особенного?**

Обычная функция возвращает **одно значение**. Но нам нужно вернуть **два**:
1. Результат деления
2. Флаг успеха (получилось ли поделить)

**Решение:** передаём переменную `success` **по ссылке** (`bool &success`).

**Что значит "по ссылке"?**
- Обычная передача: функция получает **копию** переменной, изменения не влияют на оригинал
- Передача по ссылке: функция работает с **оригинальной** переменной, изменения видны снаружи

```cpp
// Пример:
bool my_success;
double result = divide(10, 0, my_success);
// После вызова: my_success == false, result == 0
```

### Шаг 3: Функция showMenu - показ меню

```cpp
void showMenu() {
    cout << "\n=== Калькулятор ===" << endl;
    cout << "1. Сложение (+)" << endl;
    cout << "2. Вычитание (-)" << endl;
    // ... и так далее
}
```

**Что значит `void`?**
Функция ничего не возвращает. Она просто выполняет действия (выводит текст на экран).

### Шаг 4: Функция calculate - основная логика

```cpp
void calculate() {
    int choice;
    double num1, num2, result;
    
    showMenu();
    cin >> choice;
    
    if (choice == 0) {
        cout << "До свидания!" << endl;
        return;  // выход из функции
    }
    
    // ... проверка choice ...
    
    switch (choice) {
        case 1:
            result = add(num1, num2);
            cout << "Результат: " << num1 << " + " << num2 << " = " << result << endl;
            break;
        // ... другие case ...
    }
}
```

**Что здесь нового?**

#### Оператор switch
```cpp
switch (choice) {
    case 1:
        // код для choice == 1
        break;
    case 2:
        // код для choice == 2
        break;
    // ...
}
```

**Как работает switch:**
1. Проверяет значение `choice`
2. Переходит к соответствующему `case`
3. Выполняет код до `break`
4. `break` - выход из switch (иначе выполнится следующий case!)

**Switch vs if-else:**
- `switch` - когда проверяем **одно значение** на **конкретные варианты**
- `if-else` - когда проверяем **разные условия** (сравнения, логические операторы)

#### Оператор return в середине функции
```cpp
if (choice == 0) {
    cout << "До свидания!" << endl;
    return;  // немедленный выход из функции
}
```

`return` не только возвращает значение, но и **немедленно завершает функцию**. Это удобно для досрочного выхода.

### Шаг 5: Главный цикл в main

```cpp
int main() {
    while (true) {
        calculate();
        
        cout << "\nХотите выполнить ещё одну операцию? (1 - да, 0 - нет): ";
        int continue_choice;
        cin >> continue_choice;
        
        if (continue_choice == 0) {
            cout << "До свидания!" << endl;
            break;  // выход из цикла
        }
    }
    
    return 0;
}
```

**Что здесь нового?**

#### Цикл while(true)
```cpp
while (true) {
    // этот код будет выполняться бесконечно
}
```

`while(true)` - **бесконечный цикл**. Условие `true` всегда истинно, поэтому цикл никогда не закончится сам по себе.

**Как выйти из бесконечного цикла?**
Использовать `break`:
```cpp
while (true) {
    if (условие_выхода) {
        break;  // выход из цикла
    }
}
```

#### break vs return
- `break` - выход из **цикла** (while, for) или **switch**
- `return` - выход из **функции**

## Поток выполнения программы (детально)

Допустим, пользователь хочет:
1. Сложить 10 и 5
2. Потом возвести 2 в степень 10
3. Потом выйти

**Первая итерация цикла:**

1. Вызывается `calculate()`
2. Показывается меню
3. Пользователь вводит `1` (сложение)
4. `choice == 1`, проверка проходит
5. Пользователь вводит `10` и `5`
6. `switch` переходит к `case 1`
7. Вызывается `add(10, 5)` → возвращает `15`
8. Выводится: "Результат: 10 + 5 = 15"
9. Функция `calculate()` завершается
10. Спрашиваем: "Продолжить?"
11. Пользователь вводит `1` (да)
12. Цикл продолжается

**Вторая итерация цикла:**

1. Вызывается `calculate()`
2. Показывается меню
3. Пользователь вводит `5` (возведение в степень)
4. `choice == 5`, проверка проходит
5. Пользователь вводит `2` и `10`
6. `switch` переходит к `case 5`
7. Вызывается `power(2, 10)` → возвращает `1024`
8. Выводится: "Результат: 2 ^ 10 = 1024"
9. Функция `calculate()` завершается
10. Спрашиваем: "Продолжить?"
11. Пользователь вводит `0` (нет)
12. `break` - выход из цикла

**Завершение:**

1. Выводится: "До свидания!"
2. `return 0;` - программа завершается

## Используемые концепции C++

### 1. Функции
```cpp
тип_возврата имя_функции(параметры) {
    // код
    return значение;
}
```

Функция - это именованный блок кода, который можно вызывать много раз.

**Типы функций:**
- `void` - ничего не возвращает
- `int`, `double`, `char` - возвращает значение соответствующего типа

**Параметры:**
```cpp
void func(int a)           // передача по значению (копия)
void func(int &a)          // передача по ссылке (оригинал)
void func(const int &a)    // передача по константной ссылке (оригинал, но нельзя менять)
```

### 2. Цикл while
```cpp
while (условие) {
    // код, пока условие истинно
}
```

Цикл выполняется, пока условие `true`.

### 3. Оператор switch
```cpp
switch (переменная) {
    case значение1:
        // код
        break;
    case значение2:
        // код
        break;
    default:
        // код, если ничего не подошло
}
```

Switch проверяет переменную на конкретные значения.

### 4. Передача по ссылке
```cpp
void func(int &a) {
    a = 10;  // изменяет оригинальную переменную
}

int x = 5;
func(x);
// Теперь x == 10
```

### 5. Оператор break
```cpp
while (true) {
    if (условие) {
        break;  // выход из цикла
    }
}

switch (x) {
    case 1:
        // код
        break;  // выход из switch
}
```

### 6. Оператор return
```cpp
int func() {
    return 42;  // возвращает значение и завершает функцию
}

void func() {
    if (условие) {
        return;  // завершает функцию без возврата значения
    }
}
```

## Ограничения программы

1. **Нет проверки ввода** - если ввести букву вместо числа, программа может работать неправильно
2. **Нет истории вычислений** - нельзя использовать результат предыдущей операции
3. **Ограниченный набор операций** - только 5 базовых операций
4. **Нет обработки ошибок ввода** - программа не восстанавливается после некорректного ввода

## Что можно улучшить

1. Добавить проверку ввода (чтобы нельзя было ввести буквы)
2. Добавить больше операций (корень, логарифм, тригонометрия)
3. Сохранять историю вычислений
4. Добавить возможность использовать результат предыдущей операции
5. Добавить обработку ошибок (деление на ноль, переполнение)
6. Вынести всё в класс для лучшей организации кода

## Частые ошибки новичков

### Ошибка 1: Забыли break в switch
```cpp
// НЕПРАВИЛЬНО:
switch (choice) {
    case 1:
        cout << "Один";
        // нет break!
    case 2:
        cout << "Два";
        break;
}
// Если choice == 1, выведется "ОдинДва"

// ПРАВИЛЬНО:
switch (choice) {
    case 1:
        cout << "Один";
        break;  // есть break
    case 2:
        cout << "Два";
        break;
}
```

### Ошибка 2: Путаница между break и return
```cpp
// НЕПРАВИЛЬНО:
while (true) {
    if (условие) {
        return;  // это завершит функцию, а не цикл!
    }
}

// ПРАВИЛЬНО:
while (true) {
    if (условие) {
        break;  // это завершит цикл
    }
}
```

### Ошибка 3: Забыли передать переменную по ссылке
```cpp
// НЕПРАВИЛЬНО:
double divide(double a, double b, bool success) {
    if (b == 0) {
        success = false;  // изменяем копию, оригинал не меняется!
        return 0;
    }
    success = true;
    return a / b;
}

// ПРАВИЛЬНО:
double divide(double a, double b, bool &success) {  // обратите внимание на &
    if (b == 0) {
        success = false;  // изменяем оригинал
        return 0;
    }
    success = true;
    return a / b;
}
```

### Ошибка 4: Бесконечный цикл без условия выхода
```cpp
// НЕПРАВИЛЬНО:
while (true) {
    calculate();
    // нет условия выхода!
}

// ПРАВИЛЬНО:
while (true) {
    calculate();
    if (условие_выхода) {
        break;
    }
}
```

- **Функции** - разбиение кода на логические части
- **Циклы** - повторение действий
- **switch** - выбор из нескольких вариантов
