# Динамический массив с меню - Документация (Улучшенный вариант)

## Что это за программа

Улучшенная версия программы для работы с динамическим массивом. Основные улучшения:
- **Код разбит на функции** - каждая функция выполняет одну задачу
- **Проверка ввода** - защита от некорректного ввода
- **Обработка граничных случаев** - пустой массив, удаление последнего элемента
- **Безопасная работа с nullptr** - проверка указателя перед операциями

## Главное отличие от простой версии

**Простая версия:**
- Весь код в main() - около 200 строк
- Нет проверки ввода
- Сложно читать и поддерживать

**Улучшенная версия:**
- Код разбит на 8 функций
- Проверка ввода с очисткой потока
- Каждая функция выполняет одну задачу
- Легко читать и поддерживать

## Как работает программа (пошагово)

### Шаг 1: Функция inputNumber - ввод числа с проверкой

```cpp
int inputNumber(const string& prompt) {
    int number;
    while (true) {
        cout << prompt;
        cin >> number;
        
        if (cin.fail()) {
            cin.clear();
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            cout << "Ошибка: введите число!" << endl;
            continue;
        }
        
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
        break;
    }
    return number;
}
```

**Что здесь нового?**

Эта функция уже была в предыдущих задачах. Она:
- Запрашивает у пользователя число
- Проверяет, что ввод корректный
- Очищает поток при ошибке
- Повторяет запрос, пока ввод не будет правильным

### Шаг 2: Функция showArray - показ массива

```cpp
void showArray(const int* arr, int size) {
    if (size == 0) {
        cout << "Массив пуст!" << endl;
    }
    else {
        cout << "Массив: ";
        for (int i = 0; i < size; i++) {
            cout << arr[i] << " ";
        }
        cout << endl;
    }
}
```

**Почему `const int* arr`?**
Функция только читает массив, но не изменяет его. `const` защищает от случайного изменения.

**Проверка на пустоту:**
Если `size == 0`, сообщаем, что массив пуст.

### Шаг 3: Функция addElement - добавление в конец

```cpp
int* addElement(int* oldArray, int oldSize, int newElement, int& newSize) {
    newSize = oldSize + 1;
    int* newArray = new int[newSize];
    
    for (int i = 0; i < oldSize; i++) {
        newArray[i] = oldArray[i];
    }
    
    newArray[oldSize] = newElement;
    
    if (oldArray != nullptr) {
        delete[] oldArray;
    }
    
    return newArray;
}
```

**Что здесь особенного?**

#### Проверка nullptr перед удалением
```cpp
if (oldArray != nullptr) {
    delete[] oldArray;
}
```

Если массив был пуст (oldArray == nullptr), мы не должны вызывать `delete[]`.

#### Возврат нового массива
Функция создаёт новый массив в динамической памяти и возвращает указатель на него.

### Шаг 4: Функция removeByPosition - удаление по номеру

```cpp
int* removeByPosition(int* oldArray, int oldSize, int position, int& newSize) {
    if (position < 1 || position > oldSize) {
        cout << "Ошибка: неверный номер!" << endl;
        newSize = oldSize;
        return oldArray;
    }
    
    int index = position - 1;
    newSize = oldSize - 1;
    
    // Если массив станет пустым
    if (newSize == 0) {
        delete[] oldArray;
        return nullptr;
    }
    
    int* newArray = new int[newSize];
    
    for (int i = 0; i < index; i++) {
        newArray[i] = oldArray[i];
    }
    
    for (int i = index + 1; i < oldSize; i++) {
        newArray[i - 1] = oldArray[i];
    }
    
    delete[] oldArray;
    return newArray;
}
```

**Что здесь нового?**

#### Обработка случая, когда массив станет пустым
```cpp
if (newSize == 0) {
    delete[] oldArray;
    return nullptr;
}
```

Если удаляем последний элемент, массив станет пустым. В этом случае:
- Удаляем старый массив
- Возвращаем `nullptr` (пустой указатель)

**Зачем это нужно?**
Чтобы программа "знала", что массива больше нет, и не пыталась его использовать.

### Шаг 5: Функция removeByValue - удаление по значению

```cpp
int* removeByValue(int* oldArray, int oldSize, int value, int& newSize) {
    int index = -1;
    for (int i = 0; i < oldSize; i++) {
        if (oldArray[i] == value) {
            index = i;
            break;
        }
    }
    
    if (index == -1) {
        cout << "Элемент со значением " << value << " не найден!" << endl;
        newSize = oldSize;
        return oldArray;
    }
    
    newSize = oldSize - 1;
    
    if (newSize == 0) {
        delete[] oldArray;
        return nullptr;
    }
    
    int* newArray = new int[newSize];
    
    for (int i = 0; i < index; i++) {
        newArray[i] = oldArray[i];
    }
    
    for (int i = index + 1; i < oldSize; i++) {
        newArray[i - 1] = oldArray[i];
    }
    
    delete[] oldArray;
    cout << "Элемент " << value << " удалён!" << endl;
    return newArray;
}
```

**Что здесь особенного?**

#### Линейный поиск
```cpp
int index = -1;
for (int i = 0; i < oldSize; i++) {
    if (oldArray[i] == value) {
        index = i;
        break;
    }
}
```

Проходим по всем элементам, пока не найдём нужный. Если не нашли, `index` остаётся -1.

#### Обработка случая "не найден"
```cpp
if (index == -1) {
    cout << "Элемент со значением " << value << " не найден!" << endl;
    newSize = oldSize;
    return oldArray;
}
```

Если элемент не найден, возвращаем старый массив без изменений.

### Шаг 6: Функция insertElement - вставка на позицию

```cpp
int* insertElement(int* oldArray, int oldSize, int newElement, int position, int& newSize) {
    if (position < 1 || position > oldSize + 1) {
        cout << "Ошибка: неверная позиция!" << endl;
        newSize = oldSize;
        return oldArray;
    }
    
    int index = position - 1;
    newSize = oldSize + 1;
    int* newArray = new int[newSize];
    
    for (int i = 0; i < index; i++) {
        newArray[i] = oldArray[i];
    }
    
    newArray[index] = newElement;
    
    for (int i = index; i < oldSize; i++) {
        newArray[i + 1] = oldArray[i];
    }
    
    if (oldArray != nullptr) {
        delete[] oldArray;
    }
    
    cout << "Элемент " << newElement << " вставлен на позицию " << position << "!" << endl;
    return newArray;
}
```

**Что здесь особенного?**

#### Проверка nullptr перед удалением
```cpp
if (oldArray != nullptr) {
    delete[] oldArray;
}
```

Если массив был пуст, не пытаемся его удалять.

#### Три этапа копирования
1. Копируем элементы до позиции вставки
2. Вставляем новый элемент
3. Копируем остальные элементы со сдвигом

### Шаг 7: Функция clearArray - очистка массива

```cpp
int* clearArray(int* oldArray, int& newSize) {
    if (oldArray != nullptr) {
        delete[] oldArray;
    }
    newSize = 0;
    cout << "Массив очищен!" << endl;
    return nullptr;
}
```

**Что здесь происходит?**
1. Удаляем массив (если он был)
2. Обнуляем размер
3. Возвращаем `nullptr`

**Зачем возвращать nullptr?**
Чтобы вызывающий код "знал", что массива больше нет.

### Шаг 9: Функция main - главный цикл

```cpp
int main() {
    setlocale(LC_ALL, "Russian");
    
    int* arr = nullptr;
    int size = 0;
    
    cout << "=== Добро пожаловать в программу работы с динамическим массивом ===" << endl;
    
    while (true) {
        cout << "Текущий размер массива: " << size << endl;
        showMenu();
        
        int choice = inputNumber("Выберите действие: ");
        
        if (choice == 0) {
            cout << "До свидания!" << endl;
            break;
        }
        else if (choice == 1) {
            showArray(arr, size);
        }
        else if (choice == 2) {
            if (size == 0) {
                cout << "Массив пуст, будет создан новый массив." << endl;
            }
            int newElement = inputNumber("Введите число для добавления: ");
            int newSize;
            arr = addElement(arr, size, newElement, newSize);
            size = newSize;
            cout << "Элемент " << newElement << " добавлен!" << endl;
        }
        // ... другие операции ...
    }
    
    if (arr != nullptr) {
        delete[] arr;
    }
    
    return 0;
}
```

**Что здесь нового?**

#### Проверка пустого массива перед добавлением
```cpp
if (size == 0) {
    cout << "Массив пуст, будет создан новый массив." << endl;
}
```

Сообщаем пользователю, что будет создан новый массив.

#### Обновление указателя и размера
```cpp
arr = addElement(arr, size, newElement, newSize);
size = newSize;
```

После каждой операции обновляем оба значения.

## Поток выполнения программы (детально)

Допустим, пользователь выполняет следующие действия:
1. Добавить числа 10, 20, 30
2. Показать массив
3. Вставить число 15 на позицию 2
4. Удалить элемент номер 4
5. Удалить элемент со значением 10
6. Показать массив
7. Очистить массив
8. Выйти

**Шаг за шагом:**

1. **Добавить 10:**
   - `addElement(nullptr, 0, 10, newSize)`
   - Внутри функции:
     - newSize = 1
     - Создаётся новый массив: newArr → [0x1000]
     - Копируется 0 элементов (массив был пуст)
     - Добавляется: newArr[0] = 10
     - oldArray == nullptr, поэтому delete[] не вызывается
     - Возвращается newArr
   - После вызова:
     - arr → [0x1000]
     - size = 1
     - Память 0x1000: [10]

2. **Добавить 20:**
   - `addElement(arr, 1, 20, newSize)`
   - Внутри функции:
     - newSize = 2
     - Создаётся новый массив: newArr → [0x2000]
     - Копируется 1 элемент: newArr[0] = 10
     - Добавляется: newArr[1] = 20
     - Удаляется старый массив: delete[] arr (0x1000)
     - Возвращается newArr
   - После вызова:
     - arr → [0x2000]
     - size = 2
     - Память 0x2000: [10, 20]

3. **Добавить 30:**
   - Аналогично, arr = [10, 20, 30], size = 3

4. **Показать массив:**
   - `showArray(arr, 3)`
   - Вывод: "Массив: 10 20 30"

5. **Вставить 15 на позицию 2:**
   - `insertElement(arr, 3, 15, 2, newSize)`
   - Внутри функции:
     - index = 1
     - newSize = 4
     - Создаётся новый массив: newArr → [0x3000]
     - Копируется до индекса 1: newArr[0] = 10
     - Вставляется: newArr[1] = 15
     - Копируется после индекса 1: newArr[2] = 20, newArr[3] = 30
     - Удаляется старый массив: delete[] arr (0x2000)
     - Возвращается newArr
   - После вызова:
     - arr → [0x3000]
     - size = 4
     - Память 0x3000: [10, 15, 20, 30]

6. **Удалить элемент номер 4:**
   - `removeByPosition(arr, 4, 4, newSize)`
   - Внутри функции:
     - Проверка: 4 в диапазоне [1, 4] → OK
     - index = 3
     - newSize = 3
     - Создаётся новый массив: newArr → [0x4000]
     - Копируется до индекса 3: newArr[0]=10, newArr[1]=15, newArr[2]=20
     - После индекса 3 элементов нет
     - Удаляется старый массив: delete[] arr (0x3000)
     - Возвращается newArr
   - После вызова:
     - arr → [0x4000]
     - size = 3
     - Память 0x4000: [10, 15, 20]

7. **Удалить элемент со значением 10:**
   - `removeByValue(arr, 3, 10, newSize)`
   - Внутри функции:
     - Ищется 10: найден на индексе 0
     - newSize = 2
     - Создаётся новый массив: newArr → [0x5000]
     - Копируется до индекса 0: (ничего)
     - Копируется после индекса 0: newArr[0]=15, newArr[1]=20
     - Удаляется старый массив: delete[] arr (0x4000)
     - Возвращается newArr
   - После вызова:
     - arr → [0x5000]
     - size = 2
     - Память 0x5000: [15, 20]

8. **Показать массив:**
   - `showArray(arr, 2)`
   - Вывод: "Массив: 15 20"

9. **Очистить массив:**
   - `clearArray(arr, size)`
   - Внутри функции:
     - Удаляется массив: delete[] arr (0x5000)
     - size = 0
     - Возвращается nullptr
   - После вызова:
     - arr = nullptr
     - size = 0

10. **Выйти:**
    - choice = 0
    - break - выход из цикла
    - arr == nullptr, поэтому delete[] не вызывается
    - return 0 - программа завершается

## Используемые концепции C++

### 1. nullptr и безопасная работа с указателями
```cpp
int* arr = nullptr;
if (arr != nullptr) {
    delete[] arr;
}
```

### 2. Функции, возвращающие указатели
```cpp
int* addElement(int* oldArray, int oldSize, int newElement, int& newSize);
```

### 3. Передача по ссылке
```cpp
int& newSize
```

### 4. Обработка граничных случаев
```cpp
if (newSize == 0) {
    delete[] oldArray;
    return nullptr;
}
```

### 5. Линейный поиск
```cpp
for (int i = 0; i < oldSize; i++) {
    if (oldArray[i] == value) {
        index = i;
        break;
    }
}
```

### 6. Разделение ответственности
Каждая функция выполняет одну задачу:
- `addElement()` - только добавление
- `removeByPosition()` - только удаление по номеру
- `removeByValue()` - только удаление по значению
- `insertElement()` - только вставка
- `clearArray()` - только очистка

## Пример работы программы (детально)

Допустим, пользователь удаляет последний элемент из массива [15, 20].

**Что происходит:**

1. Исходный массив:
   ```
   arr → [0x5000]
   Память 0x5000: [15] [20]
   size = 2
   ```

2. Вызов `removeByPosition(arr, 2, 2, newSize)`:
   ```
   Внутри функции:
   - position = 2, index = 1
   - newSize = 2 - 1 = 1
   
   Проверка: newSize == 0? Нет (newSize = 1)
   
   - Создаётся новый массив: newArr → [0x6000]
   - Копируется до индекса 1: newArr[0] = 15
   - После индекса 1 элементов нет
   - Удаляется старый массив: delete[] arr (0x5000)
   - Возвращается newArr
   
   После вызова:
   arr → [0x6000]
   Память 0x6000: [15]
   size = 1
   ```

3. Теперь удаляем оставшийся элемент:
   ```
   Вызов: removeByPosition(arr, 1, 1, newSize)
   
   Внутри функции:
   - position = 1, index = 0
   - newSize = 1 - 1 = 0
   
   Проверка: newSize == 0? Да!
   
   - Удаляется старый массив: delete[] arr (0x6000)
   - Возвращается nullptr
   
   После вызова:
   arr = nullptr
   size = 0
   ```

**Важный момент:** когда массив становится пустым, функция возвращает `nullptr`, а не создаёт новый массив размером 0. Это более эффективно и безопасно.

## Ограничения программы

1. **Нет сохранения** - нельзя сохранить массив в файл
2. **Нет загрузки** - нельзя загрузить массив из файла
3. **Нет сортировки** - массив не сортируется автоматически
4. **Удаляет только первое вхождение** - если в массиве несколько одинаковых элементов, удалится только первый
5. **Нет поиска** - нельзя найти позицию элемента

## Что можно улучшить

1. Добавить сохранение/загрузку из файла
2. Добавить сортировку массива

4. Удалять все вхождения значения (а не только первое)

## Частые ошибки новичков

### Ошибка 1: Забыли проверить nullptr перед удалением
```cpp
// НЕПРАВИЛЬНО:
int* arr = nullptr;
delete[] arr;  // ошибка!

// ПРАВИЛЬНО:
if (arr != nullptr) {
    delete[] arr;
}
```

### Ошибка 2: Не обнулили указатель после очистки
```cpp
// НЕПРАВИЛЬНО:
delete[] arr;
// arr всё ещё указывает на удалённую память!

// ПРАВИЛЬНО:
delete[] arr;
arr = nullptr;
```

### Ошибка 3: Забыли обновить size после операции
```cpp
// НЕПРАВИЛЬНО:
arr = addElement(arr, size, newElement, newSize);
// size не обновлён!

// ПРАВИЛЬНО:
arr = addElement(arr, size, newElement, newSize);
size = newSize;
```

### Ошибка 4: Не обработали случай пустого массива
```cpp
// НЕПРАВИЛЬНО:
if (choice == 3) {
    int position = inputNumber("Номер: ");
    arr = removeByPosition(arr, size, position, newSize);
    // а если size == 0? будет ошибка!
}

// ПРАВИЛЬНО:
if (choice == 3) {
    if (size == 0) {
        cout << "Массив пуст!" << endl;
    }
    else {
        int position = inputNumber("Номер: ");
        arr = removeByPosition(arr, size, position, newSize);
        size = newSize;
    }
}
```

### Ошибка 5: Не освободили память перед завершением
```cpp
// НЕПРАВИЛЬНО:
int* arr = new int[10];
// используем arr
return 0;  // память не освобождена!

// ПРАВИЛЬНО:
int* arr = new int[10];
// используем arr
if (arr != nullptr) {
    delete[] arr;
}
return 0;
```
