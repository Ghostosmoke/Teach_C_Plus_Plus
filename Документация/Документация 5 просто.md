# Вставка элемента в массив - Документация (Простой вариант)

## Что это за программа

Программа создаёт массив из 5 чисел, а затем вставляет новое число на любую позицию, которую укажет пользователь.

**Главная особенность:** чтобы вставить элемент в середину массива, нужно создать **новый** массив побольше, скопировать часть старых элементов, вставить новый элемент, и скопировать оставшиеся элементы **со сдвигом**.

## Почему это сложнее, чем добавление в конец?

**Добавление в конец** (Задача 3):
- Просто копируем все элементы
- Добавляем новый элемент в последнюю позицию
- Никаких сдвигов не нужно

**Вставка в любую позицию** (эта задача):
- Копируем часть элементов до позиции вставки
- Вставляем новый элемент
- Копируем оставшиеся элементы **со сдвигом на 1 вправо**

## Как работает программа (пошагово)

### Шаг 1: Создание и заполнение массива
```cpp
int size = 5;
int* arr = new int[size];

arr[0] = 10;
arr[1] = 20;
arr[2] = 30;
arr[3] = 40;
arr[4] = 50;
```

Создаём массив из 5 элементов: [10, 20, 30, 40, 50]

### Шаг 2: Запрос нового элемента и позиции
```cpp
int newElement;
cout << "Какое число вставить? ";
cin >> newElement;

int position;
cout << "На какую позицию (от 1 до " << (size + 1) << ")? ";
cin >> position;
```

**Почему позиция от 1 до size+1?**
- Позиция 1 - вставить в начало (перед первым элементом)
- Позиция size - вставить перед последним элементом
- Позиция size+1 - вставить в конец (после последнего элемента)

**Пример для массива из 5 элементов:**
```
Позиция 1: [?] [10] [20] [30] [40] [50]  - в начало
Позиция 2: [10] [?] [20] [30] [40] [50]  - после первого
Позиция 3: [10] [20] [?] [30] [40] [50]  - в середину
Позиция 4: [10] [20] [30] [?] [40] [50]  - перед последним
Позиция 5: [10] [20] [30] [40] [?] [50]  - перед последним
Позиция 6: [10] [20] [30] [40] [50] [?]  - в конец
```

### Шаг 3: Проверка позиции
```cpp
if (position < 1 || position > size + 1) {
    cout << "Ошибка: неверная позиция!" << endl;
    delete[] arr;
    return 1;
}
```

**Зачем проверять?**
- Позиция меньше 1 - не существует
- Позиция больше size+1 - не существует (нельзя вставить дальше конца)

### Шаг 4: Преобразование позиции в индекс
```cpp
int index = position - 1;
```

**Позиция vs индекс:**
- **Позиция** - как привыкли люди: 1, 2, 3, 4, 5, 6
- **Индекс** - как в C++: 0, 1, 2, 3, 4, 5

```
Позиция:  1   2   3   4   5   6
          ↓   ↓   ↓   ↓   ↓   ↓
Индекс:   0   1   2   3   4   5
```

### Шаг 5: Создание нового массива
```cpp
int newSize = size + 1;
int* newArr = new int[newSize];
```

Новый массив на 1 элемент больше (6 элементов вместо 5).

### Шаг 6: Копирование элементов до позиции вставки
```cpp
for (int i = 0; i < index; i++) {
    newArr[i] = arr[i];
}
```

Копируем все элементы, которые находятся **до** позиции вставки.

**Пример:** если вставляем на позицию 3 (индекс 2), копируем индексы 0 и 1.

```
Старый массив: [10] [20] [30] [40] [50]
Вставка на индекс 2:
         ↓
Копируем до индекса 2:
Новый массив:  [10] [20] [  ] [  ] [  ] [  ]
```

### Шаг 7: Вставка нового элемента
```cpp
newArr[index] = newElement;
```

Кладём новый элемент на позицию `index`.

```
Новый массив:  [10] [20] [25] [  ] [  ] [  ]
                         ↑
                    новый элемент
```

### Шаг 8: Копирование остальных элементов со сдвигом
```cpp
for (int i = index; i < size; i++) {
    newArr[i + 1] = arr[i];
}
```

Копируем все элементы, которые находятся **на позиции вставки и после неё**, со сдвигом на 1 вправо.

**Почему `i + 1`?**
Потому что в новом массиве все эти элементы сдвигаются на 1 позицию вправо, чтобы освободить место для нового элемента.

**Пример:**
```
Старый массив: [10] [20] [30] [40] [50]
Вставка на индекс 2 (число 25):

Копируем с индекса 2:
- arr[2] = 30 → newArr[3] = 30  (i=2, i+1=3)
- arr[3] = 40 → newArr[4] = 40  (i=3, i+1=4)
- arr[4] = 50 → newArr[5] = 50  (i=4, i+1=5)

Новый массив:  [10] [20] [25] [30] [40] [50]
```

### Шаг 9: Освобождение старого массива
```cpp
delete[] arr;
```

Удаляем старый массив.

### Шаг 10: Вывод нового массива
```cpp
cout << "Новый массив: ";
for (int i = 0; i < newSize; i++) {
    cout << newArr[i] << " ";
}
```

Выводим результат.

### Шаг 11: Освобождение нового массива
```cpp
delete[] newArr;
```

Удаляем новый массив перед завершением программы.

## Пример работы программы (детально)

Допустим, пользователь хочет вставить число 25 на позицию 3.

**Что происходит в памяти:**

1. Создаётся массив:
   ```
   arr → [0x1000]
   Память 0x1000: [10] [20] [30] [40] [50]
   ```

2. Пользователь вводит:
   - Новое число: 25
   - Позиция: 3
   ```
   newElement = 25
   position = 3
   index = 3 - 1 = 2
   ```

3. Создаётся новый массив:
   ```
   newArr → [0x2000]
   Память 0x2000: [?] [?] [?] [?] [?] [?]
   ```

4. Копируются элементы до индекса 2:
   ```
   newArr[0] = arr[0] = 10
   newArr[1] = arr[1] = 20
   
   newArr: [10] [20] [?] [?] [?] [?]
   ```

5. Вставляется новый элемент:
   ```
   newArr[2] = 25
   
   newArr: [10] [20] [25] [?] [?] [?]
   ```

6. Копируются остальные элементы со сдвигом:
   ```
   i=2: newArr[3] = arr[2] = 30
   i=3: newArr[4] = arr[3] = 40
   i=4: newArr[5] = arr[4] = 50
   
   newArr: [10] [20] [25] [30] [40] [50]
   ```

7. Удаляется старый массив:
   ```
   delete[] arr;
   ```

8. Выводится: "Новый массив: 10 20 25 30 40 50"

9. Удаляется новый массив:
   ```
   delete[] newArr;
   ```

## Разные случаи вставки

### Случай 1: Вставка в начало (позиция 1)
```
Старый массив: [10] [20] [30] [40] [50]
Вставка: 5 на позицию 1

Шаг 1: Копируем до индекса 0 (ничего не копируем)
newArr: [?] [?] [?] [?] [?] [?]

Шаг 2: Вставляем на индекс 0
newArr: [5] [?] [?] [?] [?] [?]

Шаг 3: Копируем остальные со сдвигом
newArr: [5] [10] [20] [30] [40] [50]
```

### Случай 2: Вставка в конец (позиция size+1)
```
Старый массив: [10] [20] [30] [40] [50]
Вставка: 60 на позицию 6

Шаг 1: Копируем до индекса 5 (копируем все)
newArr: [10] [20] [30] [40] [50] [?]

Шаг 2: Вставляем на индекс 5
newArr: [10] [20] [30] [40] [50] [60]

Шаг 3: Копируем остальные (ничего не копируем)
newArr: [10] [20] [30] [40] [50] [60]
```

**Это то же самое, что добавление в конец из Задачи 3!**

## Используемые концепции C++

### 1. Динамическое выделение памяти
```cpp
int* arr = new int[5];
int* newArr = new int[6];
```

### 2. Преобразование позиции в индекс
```cpp
int index = position - 1;
```

### 3. Три этапа копирования
```cpp
// 1. Копируем до позиции вставки
for (int i = 0; i < index; i++) { ... }

// 2. Вставляем новый элемент
newArr[index] = newElement;

// 3. Копируем после позиции вставки (со сдвигом)
for (int i = index; i < size; i++) {
    newArr[i + 1] = arr[i];
}
```

### 4. Освобождение памяти
```cpp
delete[] arr;
delete[] newArr;
```

## Ограничения программы

1. **Фиксированный массив** - нельзя изменить размер во время работы
2. **Нет проверки ввода** - если ввести букву, программа может сломаться
3. **Всё в main** - код не разбит на функции
4. **Вставляет только один элемент** - нельзя вставить несколько

## Что можно улучшить

1. Разбить код на функции
2. Добавить проверку ввода
3. Сделать цикл для вставки нескольких элементов
4. Объединить с предыдущими задачами (добавление + удаление + вставка)
5. Добавить возможность вставлять несколько элементов за раз

## Частые ошибки новичков

### Ошибка 1: Забыли сдвиг при копировании
```cpp
// НЕПРАВИЛЬНО:
for (int i = index; i < size; i++) {
    newArr[i] = arr[i];  // перезаписываем новый элемент!
}

// ПРАВИЛЬНО:
for (int i = index; i < size; i++) {
    newArr[i + 1] = arr[i];  // сдвигаем на 1 вправо
}
```

### Ошибка 2: Неправильный диапазон для копирования
```cpp
// НЕПРАВИЛЬНО:
for (int i = index + 1; i < size; i++) {  // пропускаем элемент на позиции index!
    newArr[i + 1] = arr[i];
}

// ПРАВИЛЬНО:
for (int i = index; i < size; i++) {  // начинаем с index
    newArr[i + 1] = arr[i];
}
```

### Ошибка 3: Вставка до копирования
```cpp
// НЕПРАВИЛЬНО:
newArr[index] = newElement;  // вставили
for (int i = 0; i < index; i++) {
    newArr[i] = arr[i];  // копируем до
}
for (int i = index; i < size; i++) {
    newArr[i + 1] = arr[i];  // копируем после - но newArr[index] уже занят!
}

// ПРАВИЛЬНО:
for (int i = 0; i < index; i++) {
    newArr[i] = arr[i];  // сначала копируем до
}
newArr[index] = newElement;  // потом вставляем
for (int i = index; i < size; i++) {
    newArr[i + 1] = arr[i];  // потом копируем после
}
```

### Ошибка 4: Неправильная проверка позиции
```cpp
// НЕПРАВИЛЬНО:
if (position < 1 || position > size) {  // нельзя вставить в конец!
    cout << "Ошибка!" << endl;
}

// ПРАВИЛЬНО:
if (position < 1 || position > size + 1) {  // можно вставить в конец
    cout << "Ошибка!" << endl;
}
```

### Ошибка 5: Выход за границы массива
```cpp
// НЕПРАВИЛЬНО:
for (int i = index; i <= size; i++) {  // <= вместо <
    newArr[i + 1] = arr[i];  // arr[size] - выход за границы!
}

// ПРАВИЛЬНО:
for (int i = index; i < size; i++) {  // строго <
    newArr[i + 1] = arr[i];
}
```

## Итог

Эта программа показывает, как **вставить** элемент в любую позицию массива:
1. Создать новый массив побольше
2. Скопировать элементы до позиции вставки
3. Вставить новый элемент
4. Скопировать оставшиеся элементы со сдвигом на 1 вправо
5. Удалить старый массив

Важные моменты:
- **Позиция vs индекс** - люди считают с 1, C++ с 0
- **Три этапа** - копирование до, вставка, копирование после
- **Сдвиг** - элементы после позиции вставки сдвигаются на 1 вправо
- **Граничные случаи** - вставка в начало и в конец работают по-особому

Понимание этих концепций поможет в будущем работать с более сложными структурами данных, такими как связные списки, где вставка происходит без копирования всего массива.
