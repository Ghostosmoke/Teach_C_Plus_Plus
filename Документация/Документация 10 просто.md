# Документация 10: «Поворот матрицы на 90 градусов» (Простой вариант)

## README.md

### Что это за программа
Это программа на C++, которая работает с квадратной матрицей. Она:
- Запрашивает у пользователя размер матрицы (N×N)
- Позволяет заполнить матрицу числами
- Выводит исходную матрицу на экран
- **Поворачивает** матрицу на 90 градусов по часовой стрелке
- Выводит повёрнутую матрицу на экран

**Главная особенность:** матрица создаётся **статически** — с фиксированным максимальным размером 10×10.

### Что такое поворот на 90 градусов?
Поворот по часовой стрелке — это операция, при которой:
- **Первая строка** становится **последним столбцом**
- **Последняя строка** становится **первым столбцом**
- Размер матрицы **не меняется** (было N×N → осталось N×N)

Визуально:
```
Было (3×3):          Стало (3×3):
1  2  3              7  4  1
4  5  6         →    8  5  2
7  8  9              9  6  3
```

**Важно:** это отличается от транспонирования! При повороте матрица не только меняет строки и столбцы, но и разворачивается.

### Как работает программа (пошагово)

#### Шаг 1: Запрос размера матрицы
```cpp
int n;
cout << "Введите размер матрицы: ";
cin >> n;
```
Создаём переменную `n` и просим пользователя ввести размер квадратной матрицы.

**Почему квадратная?**
Потому что поворот на 90 градусов имеет смысл только для квадратных матриц. У прямоугольной матрицы после поворота изменятся размеры, и это усложняет задачу.

#### Шаг 2: Проверка размера
```cpp
if (n < 1 || n > 10) {
    cout << "Ошибка: размер должен быть от 1 до 10!" << endl;
    return 1;
}
```
Проверяем, что размер правильный.

#### Шаг 3: Создание двух матриц
```cpp
int matrix[10][10];    // исходная матрица
int result[10][10];    // результат поворота
```
**Почему две матрицы?**
Потому что мы не можем поворачивать "на месте" — это потребовало бы сложных обменов с учётом циклических зависимостей. Проще создать вторую матрицу.

#### Шаг 4: Заполнение исходной матрицы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cin >> matrix[i][j];
    }
}
```
Проходим по всем элементам и заполняем матрицу.

#### Шаг 5: Поворот матрицы — ключевая операция
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        result[j][n - 1 - i] = matrix[i][j];
    }
}
```

**Что здесь происходит?**
Это самая сложная часть задачи! Разберём формулу:

**Исходный элемент:** `matrix[i][j]` (строка i, столбец j)
**Куда он должен попасть:** `result[j][n - 1 - i]`

**Почему именно так?**

Давайте посмотрим на пример для матрицы 3×3:

```
Исходная матрица:
[0,0]=1  [0,1]=2  [0,2]=3
[1,0]=4  [1,1]=5  [1,2]=6
[2,0]=7  [2,1]=8  [2,2]=9
```

**Первая строка (i=0):** `1, 2, 3`
- `matrix[0][0]=1` → `result[0][2]` (верхний правый угол)
- `matrix[0][1]=2` → `result[1][2]` (середина правого столбца)
- `matrix[0][2]=3` → `result[2][2]` (нижний правый угол)

**Вторая строка (i=1):** `4, 5, 6`
- `matrix[1][0]=4` → `result[0][1]`
- `matrix[1][1]=5` → `result[1][1]` (центр остаётся в центре!)
- `matrix[1][2]=6` → `result[2][1]`

**Третья строка (i=2):** `7, 8, 9`
- `matrix[2][0]=7` → `result[0][0]` (верхний левый угол)
- `matrix[2][1]=8` → `result[1][0]`
- `matrix[2][2]=9` → `result[2][0]`

**Результат:**
```
7  4  1
8  5  2
9  6  3
```

**Как понять формулу `result[j][n-1-i]`?**
- Новый индекс строки = старый индекс столбца (`j`)
- Новый индекс столбца = `n - 1 - i` (инвертированный старый индекс строки)

Это как если бы мы:
1. Повернули матрицу на 90° по часовой стрелке
2. Первая строка ушла вправо и стала последним столбцом
3. Последняя строка ушла влево и стала первым столбцом

#### Шаг 6: Вывод результата
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cout << result[i][j] << "\t";
    }
    cout << endl;
}
```
Размеры не меняются, поэтому циклы идут до `n`.

### Используемые концепции C++

#### 1. Двумерные массивы
```cpp
int matrix[10][10];
int result[10][10];
```
Две матрицы — одна для исходных данных, другая для результата.

#### 2. Сложная работа с индексами
```cpp
result[j][n - 1 - i] = matrix[i][j];
```
Это ключевая формула поворота. Нужно понять, как меняются координаты.

#### 3. Вложенные циклы
Для перебора всех элементов матрицы.

### Пример работы программы (детально)

Допустим, пользователь вводит:
- Размер: 3
- Элементы:
  ```
  1  2  3
  4  5  6
  7  8  9
  ```

**Что происходит:**

1. Создаётся матрица 10×10, заполняется 3×3 часть
2. Выполняется поворот:
   ```
   i=0, j=0: result[0][2] = matrix[0][0] = 1
   i=0, j=1: result[1][2] = matrix[0][1] = 2
   i=0, j=2: result[2][2] = matrix[0][2] = 3
   
   i=1, j=0: result[0][1] = matrix[1][0] = 4
   i=1, j=1: result[1][1] = matrix[1][1] = 5
   i=1, j=2: result[2][1] = matrix[1][2] = 6
   
   i=2, j=0: result[0][0] = matrix[2][0] = 7
   i=2, j=1: result[1][0] = matrix[2][1] = 8
   i=2, j=2: result[2][0] = matrix[2][2] = 9
   ```
3. Выводится результат:
   ```
   7  4  1
   8  5  2
   9  6  3
   ```

### Ограничения программы
- **Всё в main** — код не разбит на функции
- **Нет проверки ввода** — если ввести букву, программа может работать неправильно
- **Работает один раз** — чтобы обработать другую матрицу, нужно запустить заново
- **Ограниченный размер** — максимум 10×10
- **Только квадратные матрицы** — для прямоугольных нужно другое решение

### Частые ошибки новичков

#### Ошибка 1: Неверная формула поворота
```cpp
// НЕПРАВИЛЬНО:
result[i][j] = matrix[j][i];  // это транспонирование, а не поворот!

// ПРАВИЛЬНО:
result[j][n - 1 - i] = matrix[i][j];  // это поворот на 90° по часовой
```

#### Ошибка 2: Поворот против часовой стрелки
```cpp
// ПОВОРОТ ПРОТИВ ЧАСОВОЙ СТРЕЛКИ:
result[n - 1 - j][i] = matrix[i][j];

// ПОВОРОТ ПО ЧАСОВОЙ СТРЕЛКЕ:
result[j][n - 1 - i] = matrix[i][j];
```

#### Ошибка 3: Забыли, что размеры не меняются
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < m; i++) {  // m — это для прямоугольных матриц!
    for (int j = 0; j < n; j++) {
        cout << result[i][j] << "\t";
    }
}

// ПРАВИЛЬНО:
for (int i = 0; i < n; i++) {  // для квадратных: размеры одинаковые
    for (int j = 0; j < n; j++) {
        cout << result[i][j] << "\t";
    }
}
```

#### Ошибка 4: Попытка повернуть "на месте" без понимания
```cpp
// НЕПРАВИЛЬНО (простая попытка):
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        swap(matrix[i][j], matrix[j][n - 1 - i]);  // всё сломается!
    }
}
// Элементы будут обмениваться несколько раз, результат непредсказуем

// ПРАВИЛЬНО: использовать вторую матрицу
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        result[j][n - 1 - i] = matrix[i][j];
    }
}
```

#### Ошибка 5: Путаница между строками и столбцами
```cpp
// НЕПРАВИЛЬНО:
result[n - 1 - i][j] = matrix[i][j];  // это отражение по вертикали!

// ПРАВИЛЬНО:
result[j][n - 1 - i] = matrix[i][j];  // это поворот на 90°
```
