# Документация 8: «Диагонали матрицы» (Простой вариант)

## README.md

### Что это за программа
Это программа на C++, которая работает с квадратной матрицей. Она:
- Запрашивает у пользователя размер матрицы (N×N)
- Позволяет заполнить матрицу числами
- Выводит матрицу на экран в виде таблицы
- Находит сумму элементов **главной диагонали** (от левого верхнего угла к правому нижнему)
- Находит сумму элементов **побочной диагонали** (от левого нижнего угла к правому верхнему)

**Главная особенность:** матрица создаётся **статически** - с фиксированным максимальным размером, а реальный размер задаётся пользователем.

### Как работает программа (пошагово)

#### Шаг 1: Запрос размера матрицы
```cpp
int n;
cout << "Введите размер матрицы: ";
cin >> n;
```
Создаём переменную `n` и просим пользователя ввести размер квадратной матрицы.

**Почему квадратная?**
Потому что только у квадратной матрицы (N строк = N столбцов) есть чётко определённые главная и побочная диагонали. У прямоугольной матрицы диагонали не определены однозначно.

#### Шаг 2: Проверка размера
```cpp
if (n < 1 || n > 10) {
    cout << "Ошибка: размер должен быть от 1 до 10!" << endl;
    return 1;
}
```
**Зачем проверять?**
- Если размер меньше 1 - матрица пустая, нечего обрабатывать
- Если размер больше 10 - матрица не поместится в наш статический массив (10×10)

`return 1` - завершает программу с кодом ошибки 1 (0 означает успех).

#### Шаг 3: Создание статического массива
```cpp
int matrix[10][10];
```
**Что здесь происходит?**
- Создаём двумерный массив размером 10×10 (10 строк, 10 столбцов)
- Память выделяется **заранее**, при запуске программы
- Это называется **статический массив** - его размер фиксирован

**Как устроен двумерный массив в памяти?**
```
matrix:
        [0]  [1]  [2]  ... [9]
[0]    [0,0][0,1][0,2]...[0,9]
[1]    [1,0][1,1][1,2]...[1,9]
[2]    [2,0][2,1][2,2]...[2,9]
...
[9]    [9,0][9,1][9,2]...[9,9]
```

Доступ к элементу: `matrix[i][j]` - строка `i`, столбец `j`.

**Почему статический, а не динамический?**
- Проще для понимания
- Не нужно освобождать память вручную
- Но ограничивает размер матрицы (максимум 10×10)

#### Шаг 4: Заполнение матрицы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cin >> matrix[i][j];
    }
}
```
**Вложенные циклы:**
- Внешний цикл (`i`) - перебирает строки
- Внутренний цикл (`j`) - перебирает столбцы
- Для каждой строки проходим по всем столбцам

**Порядок заполнения:**
```
matrix[0][0], matrix[0][1], matrix[0][2], ...
matrix[1][0], matrix[1][1], matrix[1][2], ...
matrix[2][0], matrix[2][1], matrix[2][2], ...
```
Сначала вся первая строка, потом вторая, и так далее.

#### Шаг 5: Вывод матрицы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cout << matrix[i][j] << "\t";
    }
    cout << endl;
}
```
**`\t` - это табуляция**, она выравнивает столбцы, чтобы матрица выглядела аккуратно.

**`endl` после каждой строки** - переход на новую строку после вывода всех элементов строки.

#### Шаг 6: Сумма главной диагонали
```cpp
int mainSum = 0;
for (int i = 0; i < n; i++) {
    mainSum += matrix[i][i];
}
```
**Главная диагональ** - это элементы, у которых **номер строки равен номеру столбца**: `i == j`.

Визуально:
```
[1]  2   3
 4  [5]  6
 7   8  [9]
```
Элементы: `matrix[0][0]`, `matrix[1][1]`, `matrix[2][2]` - то есть `matrix[i][i]`.

**Почему нужен только один цикл?**
Нам не нужно перебирать всю матрицу! Мы знаем, что на главной диагонали ровно `n` элементов, и их индексы совпадают.

#### Шаг 7: Сумма побочной диагонали
```cpp
int sideSum = 0;
for (int i = 0; i < n; i++) {
    sideSum += matrix[i][n - 1 - i];
}
```
**Побочная диагональ** - это элементы, у которых **сумма индексов равна N-1**: `i + j == n - 1`.

Визуально:
```
 1   2  [3]
 4  [5]  6
[7]  8   9
```
Элементы: `matrix[0][2]`, `matrix[1][1]`, `matrix[2][0]` - то есть `matrix[i][n-1-i]`.

**Откуда формула `n - 1 - i`?**
Если `i + j == n - 1`, то `j == n - 1 - i`.

**Важный момент:**
Центральный элемент (если N нечётное) входит в **обе диагонали**. Например, для матрицы 3×3 это `matrix[1][1] = 5`. Он учитывается в обеих суммах - это правильно!

#### Шаг 8: Вывод результатов
```cpp
cout << "\nСумма главной диагонали: " << mainSum << endl;
cout << "Сумма побочной диагонали: " << sideSum << endl;
```
Просто выводим две суммы на экран.

### Используемые концепции C++

#### 1. Двумерные массивы
```cpp
int matrix[10][10];  // 10 строк, 10 столбцов
```
Двумерный массив - это массив массивов. Каждая строка - это отдельный массив.

#### 2. Вложенные циклы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // код
    }
}
```
Цикл внутри цикла. Внешний перебирает строки, внутренний - столбцы.

#### 3. Условие для диагоналей
```cpp
// Главная диагональ:
matrix[i][i]           // i == j

// Побочная диагональ:
matrix[i][n - 1 - i]   // i + j == n - 1
```
Математические соотношения между индексами.

#### 4. Табуляция `\t`
```cpp
cout << matrix[i][j] << "\t";
```
`\t` - специальный символ, выравнивает текст по столбцам.

### Пример работы программы (детально)

Допустим, пользователь вводит:
- Размер: 3
- Элементы:
  ```
  1  2  3
  4  5  6
  7  8  9
  ```

**Что происходит в памяти:**

1. Создаётся переменная `n`:
   ```
   n = 3
   ```

2. Создаётся матрица 10×10 (но используем только 3×3):
   ```
   matrix:
   [1] [2] [3]  [0] [0] [0] ...
   [4] [5] [6]  [0] [0] [0] ...
   [7] [8] [9]  [0] [0] [0] ...
   [0] [0] [0]  [0] [0] [0] ...
   ...
   ```

3. Вычисляется сумма главной диагонали:
   ```
   mainSum = 0
   i = 0: mainSum += matrix[0][0] = 1   → mainSum = 1
   i = 1: mainSum += matrix[1][1] = 5   → mainSum = 6
   i = 2: mainSum += matrix[2][2] = 9   → mainSum = 15
   ```

4. Вычисляется сумма побочной диагонали:
   ```
   sideSum = 0
   i = 0: sideSum += matrix[0][2] = 3   → sideSum = 3
   i = 1: sideSum += matrix[1][1] = 5   → sideSum = 8
   i = 2: sideSum += matrix[2][0] = 7   → sideSum = 15
   ```

5. Выводятся результаты:
   ```
   Сумма главной диагонали: 15
   Сумма побочной диагонали: 15
   ```

### Ограничения программы
- **Всё в main** - код не разбит на функции, сложно читать и поддерживать
- **Нет проверки ввода** - если ввести букву вместо числа, программа может работать неправильно
- **Работает один раз** - чтобы обработать другую матрицу, нужно запустить программу заново
- **Ограниченный размер** - максимум 10×10
- **Нет вывода самих диагоналей** - только суммы

### Что можно улучшить
- Разбить код на функции (отдельная функция для ввода, для вывода, для вычисления сумм)
- Добавить проверку ввода
- Сделать цикл, чтобы можно было обрабатывать несколько матриц
- Выводить сами элементы диагоналей, а не только суммы
- Использовать динамические массивы для матриц любого размера
- Добавить больше операций с матрицами (транспонирование, поворот и т.д.)

### Частые ошибки новичков

#### Ошибка 1: Перебор всей матрицы для диагоналей
```cpp
// НЕПРАВИЛЬНО (работает, но неэффективно):
int mainSum = 0;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (i == j) {
            mainSum += matrix[i][j];
        }
    }
}
// Проходим n*n элементов, хотя на диагонали только n

// ПРАВИЛЬНО:
int mainSum = 0;
for (int i = 0; i < n; i++) {
    mainSum += matrix[i][i];
}
// Проходим только n элементов
```

#### Ошибка 2: Неверная формула для побочной диагонали
```cpp
// НЕПРАВИЛЬНО:
sideSum += matrix[i][n - i];  // выход за границы!
// При i = 0: matrix[0][3] - для матрицы 3x3 это выход за границы!

// ПРАВИЛЬНО:
sideSum += matrix[i][n - 1 - i];
// При i = 0: matrix[0][2] - последний столбец первой строки
```

#### Ошибка 3: Путаница между строками и столбцами
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cin >> matrix[j][i];  // поменяли местами!
    }
}
// Матрица будет заполнена транспонированной

// ПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cin >> matrix[i][j];  // сначала строка, потом столбец
    }
}
```

#### Ошибка 4: Использование прямоугольной матрицы
```cpp
// НЕПРАВИЛЬНО:
int n, m;
cin >> n >> m;  // n != m
int matrix[10][10];
// Диагонали не определены для прямоугольной матрицы!

// ПРАВИЛЬНО:
int n;
cin >> n;  // только один размер - квадратная матрица
int matrix[10][10];
```

#### Ошибка 5: Неправильный вывод матрицы
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cout << matrix[i][j];  // всё слипнется!
    }
}

// ПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cout << matrix[i][j] << "\t";  // табуляция между элементами
    }
    cout << endl;  // новая строка после каждой строки матрицы
}
```

### Итог
Эта программа демонстрирует базовые концепции работы с матрицами:
- **Двумерные массивы** - хранение данных в виде таблицы
- **Вложенные циклы** - перебор всех элементов матрицы
- **Условия для диагоналей** - математические соотношения между индексами
- **Форматированный вывод** - использование табуляции для красоты

Программа простая, но даёт понимание основ работы с матрицами, которые понадобятся в более сложных задачах.
