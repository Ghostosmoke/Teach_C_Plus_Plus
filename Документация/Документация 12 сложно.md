# Документация 12: «Зеркальное отражение матрицы» (Улучшенный вариант)

## README.md

### Что это за программа
Улучшенная версия программы для зеркального отражения матрицы. Основные улучшения:
- **Код разбит на функции** — каждая функция выполняет одну задачу
- **Проверка ввода** — защита от некорректного ввода пользователя
- **Циклическая работа** — можно обработать несколько матриц без перезапуска
- **Константные параметры** — защита данных от случайного изменения
- **Красивое оформление** — заголовки, разделители, подсказки

### Главное отличие от простой версии

**Простая версия:**
- Весь код в `main()` — сложно читать и поддерживать
- Нет проверки ввода
- Работает один раз

**Улучшенная версия:**
- Код разбит на 5 функций
- Проверка ввода с очисткой потока
- Работает циклически
- Константные параметры в функциях

### Как работает программа (пошагово)

#### Шаг 1: Функция inputSize — ввод размера с проверкой
```cpp
int inputSize(const string& prompt, int max) {
    int size;
    while (true) {
        cout << prompt;
        cin >> size;
        
        if (cin.fail()) {
            cin.clear();
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            cout << "Ошибка: введите число!" << endl;
            continue;
        }
        
        if (size >= 1 && size <= max) {
            break;
        }
        
        cout << "Ошибка: размер должен быть от 1 до " << max << "!" << endl;
    }
    return size;
}
```

**Универсальность функции:**
```cpp
int n = inputSize("Введите количество строк: ", 10);
int m = inputSize("Введите количество столбцов: ", 10);
```

#### Шаг 2: Функция fillMatrix — заполнение матрицы
```cpp
void fillMatrix(int matrix[][10], int n, int m) {
    for (int i = 0; i < n; i++) {
        cout << "Строка " << (i + 1) << ": ";
        for (int j = 0; j < m; j++) {
            cin >> matrix[i][j];
        }
    }
}
```

#### Шаг 3: Функция printMatrix — вывод матрицы
```cpp
void printMatrix(const int matrix[][10], int n, int m) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << matrix[i][j] << "\t";
        }
        cout << endl;
    }
}
```

#### Шаг 4: Функция mirrorMatrix — зеркальное отражение
```cpp
void mirrorMatrix(int matrix[][10], int n, int m) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m / 2; j++) {
            // Меняем местами элементы
            int temp = matrix[i][j];
            matrix[i][j] = matrix[i][m - 1 - j];
            matrix[i][m - 1 - j] = temp;
        }
    }
}
```

**Почему `matrix` не const?**
Потому что функция **изменяет** матрицу — делает отражение "на месте".

**Формула обмена:**
```cpp
int temp = matrix[i][j];
matrix[i][j] = matrix[i][m - 1 - j];
matrix[i][m - 1 - j] = temp;
```

#### Шаг 5: Функция processMatrix — обработка одной матрицы
```cpp
void processMatrix() {
    int n = inputSize("Введите количество строк: ", 10);
    int m = inputSize("Введите количество столбцов: ", 10);
    
    int matrix[10][10];
    
    cout << "Введите элементы матрицы (" << n << "x" << m << "):" << endl;
    fillMatrix(matrix, n, m);
    
    cout << "\nИсходная матрица:" << endl;
    printMatrix(matrix, n, m);
    
    mirrorMatrix(matrix, n, m);
    
    cout << "\nПосле зеркального отражения:" << endl;
    printMatrix(matrix, n, m);
}
```

#### Шаг 6: Главный цикл в main
```cpp
int main() {
    setlocale(LC_ALL, "Russian");
    
    cout << "=== Зеркальное отражение матрицы ===" << endl;
    
    while (true) {
        processMatrix();
        
        cout << "\nХотите обработать ещё одну матрицу? (1 - да, 0 - нет): ";
        int choice;
        cin >> choice;
        
        if (choice == 0) {
            cout << "До свидания!" << endl;
            break;
        }
    }
    
    return 0;
}
```

### Поток выполнения программы (детально)

Допустим, пользователь хочет:
1. Отразить матрицу 3×3: `1 2 3 / 4 5 6 / 7 8 9`
2. Отразить матрицу 2×4: `1 2 3 4 / 5 6 7 8`
3. Выйти

**Первая итерация:**
1. `main()` вызывает `processMatrix()`
2. `processMatrix()` запрашивает размеры: `n = 3, m = 3`
3. Создаётся матрица
4. `fillMatrix(matrix, 3, 3)` — заполняется матрица
5. `printMatrix(matrix, 3, 3)` — выводится исходная матрица
6. `mirrorMatrix(matrix, 3, 3)`:
   ```
   i=0: j=0: 1 ↔ 3  (строка: 3 2 1)
   i=1: j=0: 4 ↔ 6  (строка: 6 5 4)
   i=2: j=0: 7 ↔ 9  (строка: 9 8 7)
   ```
7. `printMatrix(matrix, 3, 3)` — выводится отражённая матрица
8. `main()` спрашивает: "Продолжить?"
9. Пользователь вводит `1`
10. Цикл продолжается

**Вторая итерация:**
- Аналогично, но с матрицей 2×4
- m/2 = 2, обрабатываем j=0 и j=1

**Третья итерация:**
- Пользователь вводит `0`
- `break` — выход из цикла
- Вывод: "До свидания!"
- `return 0` — программа завершается

### Используемые концепции C++

#### 1. Функции с разными типами возврата
```cpp
int inputSize(...);       // возвращает int
void fillMatrix(...);     // ничего не возвращает
void printMatrix(...);    // ничего не возвращает
void mirrorMatrix(...);   // ничего не возвращает
```

#### 2. Передача двумерных массивов в функции
```cpp
void fillMatrix(int matrix[][10], int n, int m);
void printMatrix(const int matrix[][10], int n, int m);
void mirrorMatrix(int matrix[][10], int n, int m);
```

#### 3. Константные параметры
```cpp
void printMatrix(const int matrix[][10], int n, int m);
```
`const` защищает данные от изменения.

#### 4. Обмен элементов (swap)
```cpp
int temp = a;
a = b;
b = temp;
```
Классический алгоритм обмена.

#### 5. Разделение ответственности
Каждая функция выполняет одну задачу:
- `inputSize()` — ввод размера
- `fillMatrix()` — заполнение матрицы
- `printMatrix()` — вывод матрицы
- `mirrorMatrix()` — отражение матрицы

### Ограничения программы
- **Ограниченный размер** — максимум 10×10
- **Только отражение слева направо** — нет других видов отражения
- **Нет сохранения результатов** — нельзя экспортировать в файл

### Частые ошибки новичков

#### Ошибка 1: Забыли, что функция изменяет матрицу
```cpp
// НЕПРАВИЛЬНО:
void mirrorMatrix(const int matrix[][10], int n, int m);
// const не позволит изменять матрицу!

// ПРАВИЛЬНО:
void mirrorMatrix(int matrix[][10], int n, int m);
// Без const, так как функция изменяет матрицу
```

#### Ошибка 2: Проход по всей строке (двойной обмен)
```cpp
// НЕПРАВИЛЬНО:
for (int j = 0; j < m; j++) {  // проходим по ВСЕЙ строке!
    // обмен
}

// ПРАВИЛЬНО:
for (int j = 0; j < m / 2; j++) {  // только половина!
    // обмен
}
```

#### Ошибка 3: Не очистили поток после ошибки ввода
```cpp
// НЕПРАВИЛЬНО:
cin >> n;
if (cin.fail()) {
    cout << "Ошибка!" << endl;
    // поток не очищен
}

// ПРАВИЛЬНО:
cin >> n;
if (cin.fail()) {
    cin.clear();
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    cout << "Ошибка!" << endl;
}
```

#### Ошибка 4: Обмен без временной переменной
```cpp
// НЕПРАВИЛЬНО:
matrix[i][j] = matrix[i][m - 1 - j];
matrix[i][m - 1 - j] = matrix[i][j];  // здесь уже новое значение!

// ПРАВИЛЬНО:
int temp = matrix[i][j];
matrix[i][j] = matrix[i][m - 1 - j];
matrix[i][m - 1 - j] = temp;
```

#### Ошибка 5: Неверная формула симметричного индекса
```cpp
// НЕПРАВИЛЬНО:
matrix[i][m - j]  // выход за границы при j=0!

// ПРАВИЛЬНО:
matrix[i][m - 1 - j]
```

### Итог
Эта программа демонстрирует продвинутые концепции C++:
