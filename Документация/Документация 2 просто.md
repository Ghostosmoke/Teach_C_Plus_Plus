# Массив чисел и его свойства - Документация (Простой вариант)

## Что это за программа

Программа создаёт массив (список чисел), заполняет его числами от пользователя, а затем вычисляет:
- Сумму всех чисел
- Среднее арифметическое
- Самое большое число (максимум)
- Самое маленькое число (минимум)

**Главная особенность:** массив создаётся **динамически** - размер определяется во время работы программы, а не в момент написания кода.

## Как работает программа (пошагово)

### Шаг 1: Запрос размера массива
```cpp
int size;
cout << "Сколько чисел будет в массиве? ";
cin >> size;
```

Создаём переменную `size` и просим пользователя ввести размер массива.

### Шаг 2: Проверка размера
```cpp
if (size < 1 || size > 100) {
    cout << "Ошибка: размер должен быть от 1 до 100!" << endl;
    return 1;
}
```

**Зачем проверять?**
- Если размер меньше 1 - массив пустой, нечего обрабатывать
- Если размер больше 100 - массив слишком большой, может не хватить памяти
- `return 1` - завершает программу с кодом ошибки 1 (0 означает успех)

### Шаг 3: Создание динамического массива
```cpp
int* arr = new int[size];
```

**Что здесь происходит?**

1. `new int[size]` - запрашиваем у операционной системы память для `size` целых чисел
2. Память выделяется в **куче** (heap) - специальной области памяти для динамических данных
3. `new` возвращает **указатель** - адрес первого элемента в памяти
4. Сохраняем этот адрес в переменную `arr` типа `int*` (указатель на int)

**Что такое указатель?**
Указатель - это переменная, которая хранит **адрес** в памяти, а не значение.

```
┌─────────────┐
│  arr: 0x1234│  ← указатель хранит адрес
└─────────────┘
       ↓
┌──────────────────────────────────────┐
│ Память в куче (адрес 0x1234):        │
│ [0] [1] [2] [3] [4] ... [size-1]     │
└──────────────────────────────────────┘
```

**Почему динамический массив?**
- Обычный массив: `int arr[10];` - размер фиксирован при написании кода
- Динамический массив: `new int[size]` - размер определяется во время работы

### Шаг 4: Заполнение массива
```cpp
for (int i = 0; i < size; i++) {
    cout << "Число " << (i + 1) << ": ";
    cin >> arr[i];
}
```

**Цикл for:**
- `int i = 0` - начинаем с 0 (индексы в массиве начинаются с 0!)
- `i < size` - продолжаем, пока не дойдём до конца массива
- `i++` - увеличиваем i на 1 после каждой итерации

**arr[i]:**
- `arr` - указатель на начало массива
- `[i]` - смещение на i элементов от начала
- `arr[0]` - первый элемент
- `arr[1]` - второй элемент
- `arr[size-1]` - последний элемент

### Шаг 5: Вычисление суммы
```cpp
int sum = 0;
for (int i = 0; i < size; i++) {
    sum = sum + arr[i];
}
```

**Алгоритм:**
1. Создаём переменную `sum` и обнуляем её
2. Проходим по всем элементам массива
3. Каждый элемент добавляем к `sum`

**Пример:**
```
Массив: [10, 20, 30]

Итерация 1: sum = 0 + 10 = 10
Итерация 2: sum = 10 + 20 = 30
Итерация 3: sum = 30 + 30 = 60

Результат: sum = 60
```

### Шаг 6: Вычисление среднего
```cpp
double average = (double)sum / size;
```

**Зачем `(double)sum`?**
- Если оба операнда `int`, деление будет **целочисленным**: 5 / 2 = 2
- Если хотя бы один операнд `double`, деление будет **дробным**: 5.0 / 2 = 2.5
- `(double)sum` - преобразуем `sum` из `int` в `double`

### Шаг 7: Поиск максимума и минимума
```cpp
int max = arr[0];
int min = arr[0];

for (int i = 1; i < size; i++) {
    if (arr[i] > max) {
        max = arr[i];
    }
    if (arr[i] < min) {
        min = arr[i];
    }
}
```

**Алгоритм поиска максимума:**
1. Предполагаем, что первый элемент - максимум
2. Проходим по остальным элементам (начинаем с 1, так как 0 уже проверили)
3. Если текущий элемент больше текущего максимума - обновляем максимум

**Пример:**
```
Массив: [10, 30, 20, 50, 40]

Начало: max = 10 (первый элемент)

Итерация 1: arr[1] = 30, 30 > 10? Да! max = 30
Итерация 2: arr[2] = 20, 20 > 30? Нет
Итерация 3: arr[3] = 50, 50 > 30? Да! max = 50
Итерация 4: arr[4] = 40, 40 > 50? Нет

Результат: max = 50
```

**Алгоритм поиска минимума:** аналогичен, но проверяем `<` вместо `>`.

### Шаг 8: Освобождение памяти
```cpp
delete[] arr;
```

**Зачем это нужно?**
Когда мы используем `new`, память выделяется в куче и **остаётся там**, пока мы её не освободим. Если не вызвать `delete[]`, память не вернётся системе - это называется **утечка памяти**.

**Правило:** на каждый `new` должен быть свой `delete`, на каждый `new[]` - свой `delete[]`.

**Что делает `delete[]`?**
- Освобождает всю память, выделенную через `new[]`
- Помечает эту память как свободную, чтобы её можно было использовать снова

## Используемые концепции C++

### 1. Динамическое выделение памяти
```cpp
int* arr = new int[size];  // выделение памяти
delete[] arr;              // освобождение памяти
```

**new vs delete:**
- `new` - запрашивает память у операционной системы
- `delete` - возвращает память обратно
- `new[]` / `delete[]` - для массивов
- `new` / `delete` - для одиночных объектов

### 2. Указатели
```cpp
int* arr;  // указатель на int
arr = new int[5];  // arr хранит адрес первого элемента
```

**Что хранит указатель?**
Адрес в памяти (число), а не значение.

### 3. Доступ к элементам массива
```cpp
arr[0]   // первый элемент
arr[1]   // второй элемент
arr[i]   // i-й элемент
```

**Важно:** индексы начинаются с 0!

### 4. Цикл for
```cpp
for (инициализация; условие; изменение) {
    // код
}
```

### 5. Преобразование типов
```cpp
(double)sum  // преобразуем int в double
```

## Пример работы программы (детально)

Допустим, пользователь вводит:
- Размер: 5
- Числа: 10, 20, 30, 40, 50

**Что происходит в памяти:**

1. Создаётся переменная `size`:
   ```
   size = 5
   ```

2. Выделяется память для массива:
   ```
   arr → [адрес 0x1234]
   
   Память по адресу 0x1234:
   [0x1234] [0x1238] [0x123C] [0x1240] [0x1244]
   ```
   (каждый int занимает 4 байта, поэтому адреса увеличиваются на 4)

3. Пользователь вводит числа:
   ```
   arr[0] = 10  (по адресу 0x1234)
   arr[1] = 20  (по адресу 0x1238)
   arr[2] = 30  (по адресу 0x123C)
   arr[3] = 40  (по адресу 0x1240)
   arr[4] = 50  (по адресу 0x1244)
   ```

4. Вычисляется сумма:
   ```
   sum = 0
   sum = 0 + 10 = 10
   sum = 10 + 20 = 30
   sum = 30 + 30 = 60
   sum = 60 + 40 = 100
   sum = 100 + 50 = 150
   ```

5. Вычисляется среднее:
   ```
   average = 150.0 / 5 = 30.0
   ```

6. Ищутся максимум и минимум:
   ```
   max = 10, min = 10 (начальные значения)
   
   i=1: arr[1]=20, 20>10? Да! max=20
   i=2: arr[2]=30, 30>20? Да! max=30
   i=3: arr[3]=40, 40>30? Да! max=40
   i=4: arr[4]=50, 50>40? Да! max=50
   
   min остаётся 10 (ни одно число не меньше)
   ```

7. Выводятся результаты:
   ```
   Сумма: 150
   Среднее: 30
   Максимум: 50
   Минимум: 10
   ```

8. Освобождается память:
   ```
   delete[] arr;
   // Память по адресу 0x1234 возвращена системе
   ```

## Ограничения программы

1. **Нет проверки ввода** - если ввести букву вместо числа, программа может работать неправильно
2. **Всё в main** - код не разбит на функции, сложно читать и поддерживать
3. **Нет повторного использования** - чтобы обработать другой массив, нужно запустить программу заново
4. **Ограниченный размер** - максимум 100 элементов

## Что можно улучшить

1. Разбить код на функции (отдельная функция для ввода, для вычисления суммы и т.д.)
2. Добавить проверку ввода
3. Сделать цикл, чтобы можно было обрабатывать несколько массивов
4. Добавить больше статистики (медиана, мода, дисперсия)
5. Добавить сортировку массива

## Частые ошибки новичков

### Ошибка 1: Забыли освободить память
```cpp
// НЕПРАВИЛЬНО:
int* arr = new int[10];
// используем arr
// забыли delete[]
// утечка памяти!

// ПРАВИЛЬНО:
int* arr = new int[10];
// используем arr
delete[] arr;  // освобождаем память
```

### Ошибка 2: Выход за границы массива
```cpp
// НЕПРАВИЛЬНО:
int* arr = new int[5];
arr[5] = 10;  // ошибка! индексы от 0 до 4

// ПРАВИЛЬНО:
int* arr = new int[5];
arr[4] = 10;  // последний элемент
```

### Ошибка 3: Использование new вместо new[]
```cpp
// НЕПРАВИЛЬНО:
int* arr = new int[5];  // создали массив
delete arr;  // ошибка! нужно delete[]

// ПРАВИЛЬНО:
int* arr = new int[5];
delete[] arr;  // правильно для массивов
```

### Ошибка 4: Целочисленное деление
```cpp
// НЕПРАВИЛЬНО:
int sum = 5;
int size = 2;
double average = sum / size;  // 5 / 2 = 2 (целочисленное деление)

// ПРАВИЛЬНО:
double average = (double)sum / size;  // 5.0 / 2 = 2.5
```

### Ошибка 5: Инициализация максимума/минимума нулём
```cpp
// НЕПРАВИЛЬНО:
int max = 0;  // а если все числа отрицательные?
for (int i = 0; i < size; i++) {
    if (arr[i] > max) max = arr[i];
}

// ПРАВИЛЬНО:
int max = arr[0];  // берём первый элемент
for (int i = 1; i < size; i++) {
    if (arr[i] > max) max = arr[i];
}
```

## Итог

Эта программа демонстрирует важные концепции:
- **Динамическое выделение памяти** - создание массивов во время работы программы
- **Указатели** - работа с адресами памяти
- **Циклы** - обработка всех элементов массива
- **Алгоритмы** - поиск суммы, среднего, максимума, минимума
- **Управление памятью** - обязательное освобождение памяти
