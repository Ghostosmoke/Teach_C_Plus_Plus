
# Документация 9: «Транспонирование матрицы» (Улучшенный вариант)

## README.md

### Что это за программа
Улучшенная версия программы для транспонирования матрицы. Основные улучшения:
- **Код разбит на функции** — каждая функция выполняет одну задачу
- **Проверка ввода** — защита от некорректного ввода пользователя
- **Циклическая работа** — можно обработать несколько матриц без перезапуска
- **Константные параметры** — защита данных от случайного изменения
- **Красивое оформление** — заголовки, разделители, подсказки

### Главное отличие от простой версии

**Простая версия:**
- Весь код в `main()` — сложно читать и поддерживать
- Нет проверки ввода
- Работает один раз

**Улучшенная версия:**
- Код разбит на 5 функций
- Проверка ввода с очисткой потока
- Работает циклически
- Константные параметры в функциях

### Как работает программа (пошагово)

#### Шаг 1: Функция inputSize — ввод размера с проверкой
```cpp
int inputSize(const string& prompt, int max) {
    int size;
    while (true) {
        cout << prompt;
        cin >> size;
        
        if (cin.fail()) {
            cin.clear();
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            cout << "Ошибка: введите число!" << endl;
            continue;
        }
        
        if (size >= 1 && size <= max) {
            break;
        }
        
        cout << "Ошибка: размер должен быть от 1 до " << max << "!" << endl;
    }
    return size;
}
```

**Что здесь нового?**

**Параметр `const string& prompt`**
- `const` — обещание не изменять строку
- `&` — передача по ссылке (не создаётся копия строки)
- `prompt` — текст подсказки, которую нужно вывести

**Универсальность функции:**
```cpp
int n = inputSize("Введите количество строк: ", 10);
int m = inputSize("Введите количество столбцов: ", 10);
```
Одна и та же функция работает для разных запросов — просто меняем текст подсказки.

**Проверка `cin.fail()`**
Если пользователь ввёл букву вместо числа, `cin.fail()` возвращает `true`. Очищаем поток и просим ввести снова.

#### Шаг 2: Функция fillMatrix — заполнение матрицы
```cpp
void fillMatrix(int matrix[][10], int n, int m) {
    cout << "Введите элементы матрицы (" << n << "x" << m << "):" << endl;
    for (int i = 0; i < n; i++) {
        cout << "Строка " << (i + 1) << ": ";
        for (int j = 0; j < m; j++) {
            cin >> matrix[i][j];
        }
    }
}
```

**Почему `int matrix[][10]`, а не `int matrix[10][10]`?**
При передаче двумерного массива в функцию нужно указать **второе измерение**. Первое можно опустить — компилятору важно знать, сколько элементов в строке, чтобы правильно вычислять адреса.

**Подсказка "Строка N:"**
Помогает пользователю понять, какую строку он сейчас заполняет.

#### Шаг 3: Функция printMatrix — вывод матрицы
```cpp
void printMatrix(const int matrix[][10], int n, int m) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << matrix[i][j] << "\t";
        }
        cout << endl;
    }
}
```

**Почему `const int matrix[][10]`?**
- `const` — обещание не изменять матрицу
- Функция только читает данные, не изменяет их
- Защита от случайных ошибок

**Универсальность функции:**
Одна и та же функция выводит и исходную, и транспонированную матрицу — просто передаём разные размеры.

#### Шаг 4: Функция transposeMatrix — транспонирование
```cpp
void transposeMatrix(const int source[][10], int result[][10], int n, int m) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            result[j][i] = source[i][j];
        }
    }
}
```

**Почему `source` — const, а `result` — нет?**
- `source` — исходная матрица, её не меняем
- `result` — матрица результата, её заполняем

**Формула транспонирования:**
```cpp
result[j][i] = source[i][j];
```
Индексы меняются местами — это и есть транспонирование.

#### Шаг 5: Функция processMatrix — обработка одной матрицы
```cpp
void processMatrix() {
    int n = inputSize("Введите количество строк: ", 10);
    int m = inputSize("Введите количество столбцов: ", 10);
    
    int matrix[10][10];
    int transposed[10][10];
    
    fillMatrix(matrix, n, m);
    
    cout << "\nИсходная матрица (" << n << "x" << m << "):" << endl;
    printMatrix(matrix, n, m);
    
    transposeMatrix(matrix, transposed, n, m);
    
    cout << "\nТранспонированная матрица (" << m << "x" << n << "):" << endl;
    printMatrix(transposed, m, n);
}
```

**Что делает эта функция?**
Это "оркестратор" — она координирует работу всех остальных функций:
1. Запрашивает размеры
2. Создаёт матрицы
3. Заполняет исходную матрицу
4. Выводит исходную матрицу
5. Транспонирует
6. Выводит результат

**Важный момент:**
Обратите внимание, что при выводе транспонированной матрицы передаём размеры `m, n` (в обратном порядке), а не `n, m`.

#### Шаг 6: Главный цикл в main
```cpp
int main() {
    setlocale(LC_ALL, "Russian");
    
    cout << "=== Транспонирование матрицы ===" << endl;
    
    while (true) {
        processMatrix();
        
        cout << "\nХотите обработать ещё одну матрицу? (1 - да, 0 - нет): ";
        int choice;
        cin >> choice;
        
        if (choice == 0) {
            cout << "До свидания!" << endl;
            break;
        }
    }
    
    return 0;
}
```

**Что такое `setlocale`?**
```cpp
setlocale(LC_ALL, "Russian");
```
Настраивает локаль для корректного отображения русского текста в консоли.

### Поток выполнения программы (детально)

Допустим, пользователь хочет:
1. Транспонировать матрицу 2×3: `1 2 3 / 4 5 6`
2. Транспонировать матрицу 3×2: `10 20 / 30 40 / 50 60`
3. Выйти

**Первая итерация:**
1. `main()` вызывает `processMatrix()`
2. `processMatrix()` вызывает `inputSize("строки", 10)`
3. Пользователь вводит `2`
4. `inputSize()` возвращает `2`
5. `processMatrix()` вызывает `inputSize("столбцы", 10)`
6. Пользователь вводит `3`
7. `inputSize()` возвращает `3`
8. `processMatrix()` создаёт две матрицы
9. `processMatrix()` вызывает `fillMatrix(matrix, 2, 3)`
10. Пользователь вводит: `1 2 3 4 5 6`
11. `processMatrix()` вызывает `printMatrix(matrix, 2, 3)`
12. Выводится исходная матрица
13. `processMatrix()` вызывает `transposeMatrix(matrix, transposed, 2, 3)`
14. Внутри `transposeMatrix`:
    ```
    i=0, j=0: transposed[0][0] = matrix[0][0] = 1
    i=0, j=1: transposed[1][0] = matrix[0][1] = 2
    i=0, j=2: transposed[2][0] = matrix[0][2] = 3
    i=1, j=0: transposed[0][1] = matrix[1][0] = 4
    i=1, j=1: transposed[1][1] = matrix[1][1] = 5
    i=1, j=2: transposed[2][1] = matrix[1][2] = 6
    ```
15. `processMatrix()` вызывает `printMatrix(transposed, 3, 2)` — **обратите внимание на порядок размеров!**
16. Выводится транспонированная матрица:
    ```
    1  4
    2  5
    3  6
    ```
17. `main()` спрашивает: "Продолжить?"
18. Пользователь вводит `1`
19. Цикл продолжается

**Вторая итерация:**
- Аналогично, но с матрицей 3×2
- Результат — матрица 2×3

**Третья итерация:**
- Пользователь вводит `0`
- `break` — выход из цикла
- Вывод: "До свидания!"
- `return 0` — программа завершается

### Используемые концепции C++

#### 1. Функции с разными типами возврата
```cpp
int inputSize(...);           // возвращает int
void fillMatrix(...);         // ничего не возвращает
void printMatrix(...);        // ничего не возвращает
void transposeMatrix(...);    // ничего не возвращает
```

#### 2. Передача двумерных массивов в функции
```cpp
void fillMatrix(int matrix[][10], int n, int m);
void printMatrix(const int matrix[][10], int n, int m);
void transposeMatrix(const int source[][10], int result[][10], int n, int m);
```
При передаче двумерного массива нужно указать **второе измерение**.

#### 3. Константные параметры
```cpp
void printMatrix(const int matrix[][10], int n, int m);
void transposeMatrix(const int source[][10], int result[][10], int n, int m);
```
`const` защищает данные от изменения.

#### 4. Передача по константной ссылке
```cpp
int inputSize(const string& prompt, int max);
```
- `const` — не меняем строку
- `&` — не создаём копию (экономия памяти)

#### 5. Разделение ответственности
Каждая функция выполняет одну задачу:
- `inputSize()` — ввод размера
- `fillMatrix()` — заполнение матрицы
- `printMatrix()` — вывод матрицы
- `transposeMatrix()` — транспонирование

### Пример работы программы (детально)

Допустим, пользователь вводит:
- Строки: 2
- Столбцы: 3
- Элементы:
  ```
  1  2  3
  4  5  6
  ```

**Что происходит:**
1. `inputSize()` возвращает `n = 2`
2. `inputSize()` возвращает `m = 3`
3. Создаются две матрицы: `matrix[10][10]`, `transposed[10][10]`
4. `fillMatrix()` заполняет matrix:
   ```
   matrix[0][0] = 1, matrix[0][1] = 2, matrix[0][2] = 3
   matrix[1][0] = 4, matrix[1][1] = 5, matrix[1][2] = 6
   ```
5. `printMatrix(matrix, 2, 3)` выводит:
   ```
   1  2  3
   4  5  6
   ```
6. `transposeMatrix()` выполняет:
   ```
   transposed[0][0] = 1, transposed[1][0] = 2, transposed[2][0] = 3
   transposed[0][1] = 4, transposed[1][1] = 5, transposed[2][1] = 6
   ```
7. `printMatrix(transposed, 3, 2)` выводит:
   ```
   1  4
   2  5
   3  6
   ```

### Ограничения программы
- **Ограниченный размер** — максимум 10×10
- **Нет transpose "на месте"** — для квадратных матриц можно было бы экономить память
- **Нет дополнительных операций** — только транспонирование
- **Нет сохранения результатов** — нельзя экспортировать в файл

### Что можно улучшить
- Для квадратных матриц делать transpose "на месте" (без второй матрицы)
- Добавить другие операции с матрицами (поворот, отражение, умножение)
- Использовать динамические массивы для матриц любого размера
- Добавить проверку, что матрица не пустая
- Добавить возможность загрузки матрицы из файла
- Добавить визуализацию (подсветку строк/столбцов)

### Частые ошибки новичков

#### Ошибка 1: Забыли const в параметре функции
```cpp
// НЕПРАВИЛЬНО:
void printMatrix(int matrix[][10], int n, int m);
// Функция может случайно изменить матрицу

// ПРАВИЛЬНО:
void printMatrix(const int matrix[][10], int n, int m);
// Функция обещает не изменять матрицу
```

#### Ошибка 2: Неверная передача двумерного массива
```cpp
// НЕПРАВИЛЬНО:
void fillMatrix(int matrix[][], int n, int m);  // не указан размер второго измерения!

// ПРАВИЛЬНО:
void fillMatrix(int matrix[][10], int n, int m);  // второе измерение указано
```

#### Ошибка 3: Перепутали размеры при выводе результата
```cpp
// НЕПРАВИЛЬНО:
printMatrix(transposed, n, m);  // n и m — размеры исходной матрицы!

// ПРАВИЛЬНО:
printMatrix(transposed, m, n);  // m и n — размеры транспонированной матрицы!
```

#### Ошибка 4: Не очистили поток после ошибки ввода
```cpp
// НЕПРАВИЛЬНО:
cin >> n;
if (cin.fail()) {
    cout << "Ошибка!" << endl;
    // поток не очищен, следующие cin будут сразу завершаться с ошибкой
}

// ПРАВИЛЬНО:
cin >> n;
if (cin.fail()) {
    cin.clear();
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    cout << "Ошибка!" << endl;
}
```

#### Ошибка 5: Попытка transpose "на месте" для прямоугольной матрицы
```cpp
// НЕПРАВИЛЬНО (для прямоугольной матрицы):
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        swap(matrix[i][j], matrix[j][i]);  // выход за границы!
    }
}

// ПРАВИЛЬНО:
// Используем вторую матрицу для результата
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        transposed[j][i] = matrix[i][j];
    }
}
```

### Итог
Эта программа демонстрирует продвинутые концепции C++:
- **Функции** — разбиение кода на логические части
- **Константные параметры** — защита данных
- **Проверка ввода** — защита от некорректных данных
- **Очистка потока** — восстановление после ошибок ввода
- **Разделение ответственности** — каждая функция делает одно дело
- **Универсальность функций** — одна функция работает для разных случаев

Код стал более читаемым, безопасным и поддерживаемым. Каждая функция легко тестируется и может быть переиспользована в других программах.
