# Удаление элемента из массива - Документация (Простой вариант)

## Что это за программа

Программа создаёт массив из 7 чисел, а затем удаляет из него один элемент по номеру, который вводит пользователь.

**Главная особенность:** как и при добавлении, чтобы удалить элемент, нужно создать **новый** массив поменьше, скопировать туда все элементы **кроме удаляемого**, и удалить старый массив.

## Почему это сложно?

В C++ массив имеет **фиксированный размер**. Нельзя просто "удалить" элемент - массив останется того же размера. Нужно:

1. Создать новый массив размером на 1 меньше
2. Скопировать все элементы, **пропуская** тот, который нужно удалить
3. Удалить старый массив
4. Теперь работаем с новым массивом

## Как работает программа (пошагово)

### Шаг 1: Создание и заполнение массива
```cpp
int size = 7;
int* arr = new int[size];

arr[0] = 10;
arr[1] = 20;
arr[2] = 30;
arr[3] = 40;
arr[4] = 50;
arr[5] = 60;
arr[6] = 70;
```

Создаём массив из 7 элементов и заполняем его числами.

### Шаг 2: Вывод исходного массива
```cpp
cout << "Исходный массив: ";
for (int i = 0; i < size; i++) {
    cout << arr[i] << " ";
}
```

Выводим все элементы через пробел.

### Шаг 3: Запрос номера элемента для удаления
```cpp
int position;
cout << "Какой элемент удалить (по номеру от 1 до " << size << ")? ";
cin >> position;
```

Пользователь вводит **номер** элемента (начинается с 1, как привыкли люди).

### Шаг 4: Проверка номера
```cpp
if (position < 1 || position > size) {
    cout << "Ошибка: неверный номер!" << endl;
    delete[] arr;
    return 1;
}
```

**Зачем проверять?**
- Номер меньше 1 - такого элемента нет
- Номер больше 7 - такого элемента нет
- Если не проверить, программа может сломаться или удалить не то

**Важно:** перед выходом из программы с ошибкой (`return 1`) нужно освободить память (`delete[] arr`), иначе будет утечка.

### Шаг 5: Преобразование номера в индекс
```cpp
int index = position - 1;
```

**Номер vs индекс:**
- **Номер** - как привыкли люди: 1, 2, 3, 4, 5, 6, 7
- **Индекс** - как в C++: 0, 1, 2, 3, 4, 5, 6

```
Номер:   1   2   3   4   5   6   7
         ↓   ↓   ↓   ↓   ↓   ↓   ↓
Индекс:  0   1   2   3   4   5   6
Элемент: 10  20  30  40  50  60  70
```

### Шаг 6: Создание нового массива
```cpp
int newSize = size - 1;
int* newArr = new int[newSize];
```

Новый массив на 1 элемент меньше (6 элементов вместо 7).

### Шаг 7: Копирование элементов до удаляемого
```cpp
for (int i = 0; i < index; i++) {
    newArr[i] = arr[i];
}
```

Копируем все элементы, которые находятся **до** удаляемого.

**Пример:** если удаляем элемент с индексом 2 (число 30), копируем индексы 0 и 1.

```
Старый массив: [10] [20] [30] [40] [50] [60] [70]
                         ↑
                    удаляем (индекс 2)

Копируем до индекса 2:
Новый массив:  [10] [20] [  ] [  ] [  ] [  ]
```

### Шаг 8: Копирование элементов после удаляемого
```cpp
for (int i = index + 1; i < size; i++) {
    newArr[i - 1] = arr[i];
}
```

Копируем все элементы, которые находятся **после** удаляемого.

**Почему `i - 1`?**
Потому что в новом массиве все элементы после удаляемого сдвигаются на 1 позицию влево.

**Пример:**
```
Старый массив: [10] [20] [30] [40] [50] [60] [70]
                         ↑
                    удаляем (индекс 2)

Копируем после индекса 2:
- arr[3] = 40 → newArr[2] = 40  (i=3, i-1=2)
- arr[4] = 50 → newArr[3] = 50  (i=4, i-1=3)
- arr[5] = 60 → newArr[4] = 60  (i=5, i-1=4)
- arr[6] = 70 → newArr[5] = 70  (i=6, i-1=5)

Новый массив:  [10] [20] [40] [50] [60] [70]
```

### Шаг 9: Освобождение старого массива
```cpp
delete[] arr;
```

Удаляем старый массив.

### Шаг 10: Вывод нового массива
```cpp
cout << "Новый массив: ";
for (int i = 0; i < newSize; i++) {
    cout << newArr[i] << " ";
}
```

Выводим результат.

### Шаг 11: Освобождение нового массива
```cpp
delete[] newArr;
```

Удаляем новый массив перед завершением программы.

## Пример работы программы (детально)

Допустим, пользователь хочет удалить элемент номер 3 (число 30).

**Что происходит в памяти:**

1. Создаётся массив:
   ```
   arr → [0x1000]
   Память 0x1000: [10] [20] [30] [40] [50] [60] [70]
   ```

2. Пользователь вводит номер: 3
   ```
   position = 3
   index = 3 - 1 = 2
   ```

3. Создаётся новый массив:
   ```
   newArr → [0x2000]
   Память 0x2000: [?] [?] [?] [?] [?] [?]
   ```

4. Копируются элементы до индекса 2:
   ```
   newArr[0] = arr[0] = 10
   newArr[1] = arr[1] = 20
   
   newArr: [10] [20] [?] [?] [?] [?]
   ```

5. Копируются элементы после индекса 2:
   ```
   i=3: newArr[2] = arr[3] = 40
   i=4: newArr[3] = arr[4] = 50
   i=5: newArr[4] = arr[5] = 60
   i=6: newArr[5] = arr[6] = 70
   
   newArr: [10] [20] [40] [50] [60] [70]
   ```

6. Удаляется старый массив:
   ```
   delete[] arr;
   ```

7. Выводится: "Новый массив: 10 20 40 50 60 70"

8. Удаляется новый массив:
   ```
   delete[] newArr;
   ```

## Используемые концепции C++

### 1. Динамическое выделение памяти
```cpp
int* arr = new int[7];
int* newArr = new int[6];
```

### 2. Преобразование номера в индекс
```cpp
int index = position - 1;
```

Люди считают с 1, C++ - с 0.

### 3. Два цикла для копирования
```cpp
// До удаляемого
for (int i = 0; i < index; i++) { ... }

// После удаляемого (со сдвигом)
for (int i = index + 1; i < size; i++) {
    newArr[i - 1] = arr[i];
}
```

### 4. Освобождение памяти
```cpp
delete[] arr;
delete[] newArr;
```

## Ограничения программы

1. **Фиксированный массив** - нельзя изменить размер во время работы
2. **Нет проверки ввода** - если ввести букву, программа может сломаться
3. **Всё в main** - код не разбит на функции
4. **Удаляет только один элемент** - нельзя удалить несколько

## Что можно улучшить

1. Разбить код на функции
2. Добавить проверку ввода
3. Сделать цикл для удаления нескольких элементов
4. Добавить возможность удалять по значению (а не по номеру)
5. Добавить возможность объединять с предыдущими задачами (добавление + удаление)

## Частые ошибки новичков

### Ошибка 1: Забыли преобразовать номер в индекс
```cpp
// НЕПРАВИЛЬНО:
int position = 3;
// используем position как индекс
arr[position] = ...  // это 4-й элемент, а не 3-й!

// ПРАВИЛЬНО:
int position = 3;
int index = position - 1;  // теперь index = 2, это 3-й элемент
```

### Ошибка 2: Скопировали удаляемый элемент
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i <= index; i++) {  // <= вместо <
    newArr[i] = arr[i];  // скопировали удаляемый элемент!
}

// ПРАВИЛЬНО:
for (int i = 0; i < index; i++) {  // строго <
    newArr[i] = arr[i];
}
```

### Ошибка 3: Неправильный сдвиг при копировании
```cpp
// НЕПРАВИЛЬНО:
for (int i = index + 1; i < size; i++) {
    newArr[i] = arr[i];  // неправильный индекс в newArr!
}

// ПРАВИЛЬНО:
for (int i = index + 1; i < size; i++) {
    newArr[i - 1] = arr[i];  // сдвигаем на 1 влево
}
```

### Ошибка 4: Не освободили память при ошибке
```cpp
// НЕПРАВИЛЬНО:
if (position < 1 || position > size) {
    cout << "Ошибка!" << endl;
    return 1;  // память не освобождена!
}

// ПРАВИЛЬНО:
if (position < 1 || position > size) {
    cout << "Ошибка!" << endl;
    delete[] arr;  // освобождаем память
    return 1;
}
```

### Ошибка 5: Попытка удалить из пустого массива
```cpp
// НЕПРАВИЛЬНО:
int size = 0;
int* arr = new int[size];  // массив из 0 элементов
// пытаемся удалить элемент - ошибка!

// ПРАВИЛЬНО:
if (size == 0) {
    cout << "Массив пуст!" << endl;
    return 1;
}
```

## Итог

Эта программа показывает, как **удалить** элемент из массива:
1. Создать новый массив поменьше
2. Скопировать все элементы, кроме удаляемого
3. Удалить старый массив

Важные моменты:
- **Номер vs индекс** - люди считают с 1, C++ с 0
- **Два цикла** - один для элементов до удаляемого, другой для элементов после
- **Сдвиг** - элементы после удаляемого сдвигаются на 1 влево
