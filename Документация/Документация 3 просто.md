# Добавление элемента в массив - Документация (Простой вариант)

## Что это за программа

Программа создаёт массив из 5 чисел, заполняет его числами от пользователя, а затем добавляет ещё одно число в конец массива.

**Главная особенность:** чтобы добавить элемент в массив, нужно создать **новый** массив побольше, скопировать туда старые данные, добавить новое число, и удалить старый массив.

## Почему это сложно?

В C++ массив имеет **фиксированный размер**. Если создали массив на 5 элементов - он таким и останется. Нельзя просто "добавить" элемент в существующий массив.

**Что нужно сделать:**
1. Создать новый массив размером на 1 больше
2. Скопировать все старые элементы в новый массив
3. Добавить новое число в конец
4. Удалить старый массив
5. Теперь работаем с новым массивом

## Как работает программа (пошагово)

### Шаг 1: Создание исходного массива
```cpp
int size = 5;
int* arr = new int[size];
```

Создаём массив из 5 элементов в динамической памяти.

### Шаг 2: Заполнение массива
```cpp
for (int i = 0; i < size; i++) {
    cout << "Число " << (i + 1) << ": ";
    cin >> arr[i];
}
```

Пользователь вводит 5 чисел, которые сохраняются в массив.

### Шаг 3: Вывод исходного массива
```cpp
cout << "Исходный массив: ";
for (int i = 0; i < size; i++) {
    cout << arr[i] << " ";
}
```

Выводим все элементы массива через пробел.

### Шаг 4: Запрос нового элемента
```cpp
int newElement;
cout << "Какое число добавить? ";
cin >> newElement;
```

Спрашиваем у пользователя число, которое нужно добавить.

### Шаг 5: Создание нового массива
```cpp
int newSize = size + 1;
int* newArr = new int[newSize];
```

Создаём новый массив размером `size + 1` (на 1 элемент больше).

### Шаг 6: Копирование элементов
```cpp
for (int i = 0; i < size; i++) {
    newArr[i] = arr[i];
}
```

**Важный момент:** копируем **все** элементы из старого массива в новый.

**Как это работает:**
```
Старый массив: [10, 20, 30, 40, 50]
                ↓    ↓    ↓    ↓    ↓
Новый массив:  [10, 20, 30, 40, 50, ?]
```

Цикл проходит по всем элементам старого массива (от 0 до size-1) и копирует каждый в новый массив.

### Шаг 7: Добавление нового элемента
```cpp
newArr[size] = newElement;
```

Добавляем новое число на позицию `size` (последняя позиция в новом массиве).

**Почему именно `size`?**
- Новый массив имеет размер `size + 1`
- Индексы: от 0 до `size`
- Последняя позиция: `size`

```
Старый массив: [10, 20, 30, 40, 50]
Новый массив:  [10, 20, 30, 40, 50, 60]
                                          ↑
                                      newArr[5] = 60
```

### Шаг 8: Освобождение старого массива
```cpp
delete[] arr;
```

Удаляем старый массив, так как он больше не нужен.

**Важно:** удаляем **после** копирования! Если удалить до копирования, потеряем данные.

### Шаг 9: Вывод нового массива
```cpp
cout << "Новый массив: ";
for (int i = 0; i < newSize; i++) {
    cout << newArr[i] << " ";
}
```

Выводим все элементы нового массива.

### Шаг 10: Освобождение нового массива
```cpp
delete[] newArr;
```

Удаляем новый массив перед завершением программы.

## Пример работы программы (детально)

Допустим, пользователь вводит:
- Числа: 10, 20, 30, 40, 50
- Новое число: 60

**Что происходит в памяти:**

1. Создаётся массив `arr`:
   ```
   arr → [адрес 0x1000]
   
   Память по адресу 0x1000:
   [10] [20] [30] [40] [50]
   ```

2. Пользователь вводит числа:
   ```
   arr[0] = 10
   arr[1] = 20
   arr[2] = 30
   arr[3] = 40
   arr[4] = 50
   ```

3. Выводится: "Исходный массив: 10 20 30 40 50"

4. Пользователь вводит новое число: 60
   ```
   newElement = 60
   ```

5. Создаётся новый массив `newArr`:
   ```
   newArr → [адрес 0x2000]
   
   Память по адресу 0x2000:
   [?] [?] [?] [?] [?] [?]
   ```

6. Копируются элементы:
   ```
   newArr[0] = arr[0] = 10
   newArr[1] = arr[1] = 20
   newArr[2] = arr[2] = 30
   newArr[3] = arr[3] = 40
   newArr[4] = arr[4] = 50
   
   newArr: [10] [20] [30] [40] [50] [?]
   ```

7. Добавляется новый элемент:
   ```
   newArr[5] = 60
   
   newArr: [10] [20] [30] [40] [50] [60]
   ```

8. Удаляется старый массив:
   ```
   delete[] arr;
   // Память по адресу 0x1000 возвращена системе
   ```

9. Выводится: "Новый массив: 10 20 30 40 50 60"

10. Удаляется новый массив:
    ```
    delete[] newArr;
    // Память по адресу 0x2000 возвращена системе
    ```

## Используемые концепции C++

### 1. Динамическое выделение памяти
```cpp
int* arr = new int[5];      // создание массива
int* newArr = new int[6];   // создание нового массива
```

### 2. Копирование массивов
```cpp
for (int i = 0; i < size; i++) {
    newArr[i] = arr[i];
}
```

Построчное копирование элементов.

### 3. Освобождение памяти
```cpp
delete[] arr;
delete[] newArr;
```

Обязательное освобождение памяти после использования.

## Ограничения программы

1. **Фиксированный размер** - можно добавить только один элемент
2. **Нет проверки ввода** - если ввести букву вместо числа, программа может работать неправильно
3. **Всё в main** - код не разбит на функции
4. **Нет повторного использования** - чтобы добавить ещё один элемент, нужно запустить программу заново

## Что можно улучшить

1. Сделать цикл для добавления нескольких элементов
2. Добавить проверку ввода
3. Разбить код на функции
4. Добавить возможность удалять элементы
5. Добавить возможность вставлять элементы в любую позицию

## Частые ошибки новичков

### Ошибка 1: Удалили старый массив до копирования
```cpp
// НЕПРАВИЛЬНО:
int* newArr = new int[newSize];
delete[] arr;  // удалили до копирования!
for (int i = 0; i < size; i++) {
    newArr[i] = arr[i];  // arr уже удалён!
}

// ПРАВИЛЬНО:
int* newArr = new int[newSize];
for (int i = 0; i < size; i++) {
    newArr[i] = arr[i];  // копируем
}
delete[] arr;  // удаляем после копирования
```

### Ошибка 2: Забыли освободить память
```cpp
// НЕПРАВИЛЬНО:
int* arr = new int[5];
int* newArr = new int[6];
// используем массивы
// забыли delete[]
// утечка памяти!

// ПРАВИЛЬНО:
int* arr = new int[5];
int* newArr = new int[6];
// используем массивы
delete[] arr;
delete[] newArr;
```

### Ошибка 3: Неправильный индекс для нового элемента
```cpp
// НЕПРАВИЛЬНО:
newArr[newSize] = newElement;  // выход за границы!
// newSize = 6, но индексы от 0 до 5

// ПРАВИЛЬНО:
newArr[size] = newElement;  // size = 5, это последняя позиция
// или
newArr[newSize - 1] = newElement;  // newSize - 1 = 5
```

### Ошибка 4: Скопировали не все элементы
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < size - 1; i++) {  // пропустили последний элемент!
    newArr[i] = arr[i];
}

// ПРАВИЛЬНО:
for (int i = 0; i < size; i++) {  // копируем все элементы
    newArr[i] = arr[i];
}
```

## Итог

Эта программа демонстрирует важную концепцию: **массивы в C++ имеют фиксированный размер**. Чтобы "добавить" элемент, нужно:
1. Создать новый массив побольше
2. Скопировать старые данные
3. Добавить новый элемент
4. Удалить старый массив
