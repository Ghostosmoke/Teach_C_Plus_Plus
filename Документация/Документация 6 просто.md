# Динамический массив с меню - Документация (Простой вариант)

## Что это за программа

Это итоговая программа, которая объединяет все операции с массивами, которые мы изучили:
- Создание массива
- Добавление элементов в конец
- Удаление элементов (по номеру и по значению)
- Вставка элементов на любую позицию
- Очистка массива
- Выход из программы

**Главная особенность:** программа работает циклически - пользователь может выполнять сколько угодно операций, пока не решит выйти.

## Как работает программа (пошагово)

### Шаг 1: Инициализация переменных
```cpp
int* arr = nullptr;
int size = 0;
```

**Что такое `nullptr`?**
`nullptr` - это специальный указатель, который означает "ничего". Он говорит, что массива пока нет.

**Почему size = 0?**
Потому что массива пока нет, значит и элементов в нём 0.

### Шаг 2: Главный цикл while(true)
```cpp
while (true) {
    // показываем меню
    // обрабатываем выбор пользователя
    // если choice == 0, выходим из цикла
}
```

**Что такое `while(true)`?**
Это бесконечный цикл. Он будет выполняться, пока мы не выйдем из него с помощью `break`.

**Как выйти из цикла?**
Когда пользователь выберет "0. Выход", программа выполнит `break` и выйдет из цикла.

### Шаг 3: Меню
```cpp
cout << "=== Динамический массив ===" << endl;
cout << "Текущий размер: " << size << endl;
cout << "1. Показать массив" << endl;
cout << "2. Добавить элемент в конец" << endl;
// ... и так далее
```

Программа показывает пользователю список доступных действий.

### Шаг 4: Обработка выбора через if-else
```cpp
if (choice == 0) {
    // выход
}
else if (choice == 1) {
    // показать массив
}
else if (choice == 2) {
    // добавить элемент
}
// ... и так далее
```

Программа проверяет, что выбрал пользователь, и выполняет соответствующее действие.

### Шаг 5: Операция 1 - Показать массив
```cpp
if (size == 0) {
    cout << "Массив пуст!" << endl;
}
else {
    cout << "Массив: ";
    for (int i = 0; i < size; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}
```

**Проверка на пустоту:**
Если `size == 0`, массив пуст, и мы не можем его показать.

**Вывод элементов:**
Цикл `for` проходит по всем элементам массива и выводит их через пробел.

### Шаг 6: Операция 2 - Добавить элемент в конец
```cpp
int newElement;
cout << "Введите число для добавления: ";
cin >> newElement;

int newSize = size + 1;
int* newArr = new int[newSize];

for (int i = 0; i < size; i++) {
    newArr[i] = arr[i];
}

newArr[size] = newElement;

if (arr != nullptr) {
    delete[] arr;
}

arr = newArr;
size = newSize;
```

**Что здесь происходит?**
1. Запрашиваем у пользователя число
2. Создаём новый массив на 1 элемент больше
3. Копируем все старые элементы в новый массив
4. Добавляем новое число в конец
5. Удаляем старый массив (если он был)
6. Обновляем указатель `arr` на новый массив
7. Обновляем размер `size`

**Проверка `if (arr != nullptr)`:**
Если массив был пуст (arr == nullptr), мы не должны вызывать `delete[]`, потому что удалять нечего.

### Шаг 7: Операция 3 - Удалить элемент по номеру
```cpp
if (size == 0) {
    cout << "Массив пуст, нечего удалять!" << endl;
}
else {
    int position;
    cout << "Какой элемент удалить (от 1 до " << size << ")? ";
    cin >> position;
    
    if (position < 1 || position > size) {
        cout << "Ошибка: неверный номер!" << endl;
    }
    else {
        int index = position - 1;
        
        int newSize = size - 1;
        int* newArr = new int[newSize];
        
        for (int i = 0; i < index; i++) {
            newArr[i] = arr[i];
        }
        
        for (int i = index + 1; i < size; i++) {
            newArr[i - 1] = arr[i];
        }
        
        delete[] arr;
        
        arr = newArr;
        size = newSize;
    }
}
```

**Проверка на пустоту:**
Если массив пуст, нечего удалять.

**Проверка номера:**
Номер должен быть от 1 до size.

**Два цикла копирования:**
- Первый копирует элементы до удаляемого
- Второй копирует элементы после удаляемого (со сдвигом на 1 влево)

### Шаг 8: Операция 4 - Удалить элемент по значению
```cpp
if (size == 0) {
    cout << "Массив пуст, нечего удалять!" << endl;
}
else {
    int value;
    cout << "Какое значение удалить? ";
    cin >> value;
    
    int index = -1;
    for (int i = 0; i < size; i++) {
        if (arr[i] == value) {
            index = i;
            break;
        }
    }
    
    if (index == -1) {
        cout << "Элемент со значением " << value << " не найден!" << endl;
    }
    else {
        // удаляем элемент (как в операции 3)
    }
}
```

**Линейный поиск:**
Проходим по всем элементам массива, пока не найдём нужный.

**Если не нашли:**
`index` остаётся равным -1, и мы сообщаем пользователю, что элемент не найден.

### Шаг 9: Операция 5 - Вставить элемент на позицию
```cpp
int newElement;
cout << "Какое число вставить? ";
cin >> newElement;

int position;
cout << "На какую позицию (от 1 до " << (size + 1) << ")? ";
cin >> position;

if (position < 1 || position > size + 1) {
    cout << "Ошибка: неверная позиция!" << endl;
}
else {
    int index = position - 1;
    
    int newSize = size + 1;
    int* newArr = new int[newSize];
    
    for (int i = 0; i < index; i++) {
        newArr[i] = arr[i];
    }
    
    newArr[index] = newElement;
    
    for (int i = index; i < size; i++) {
        newArr[i + 1] = arr[i];
    }
    
    if (arr != nullptr) {
        delete[] arr;
    }
    
    arr = newArr;
    size = newSize;
}
```

**Три этапа:**
1. Копируем элементы до позиции вставки
2. Вставляем новый элемент
3. Копируем остальные элементы со сдвигом вправо

**Позиция от 1 до size+1:**
Можно вставить в начало (1), в середину, или в конец (size+1).

### Шаг 10: Операция 6 - Очистить массив
```cpp
if (size == 0) {
    cout << "Массив уже пуст!" << endl;
}
else {
    delete[] arr;
    arr = nullptr;
    size = 0;
    cout << "Массив очищен!" << endl;
}
```

**Что происходит?**
1. Удаляем массив из памяти
2. Обнуляем указатель (arr = nullptr)
3. Обнуляем размер (size = 0)

**Зачем обнулять указатель?**
Чтобы программа "забыла" про старый массив и не попыталась его использовать.

### Шаг 11: Освобождение памяти перед завершением
```cpp
if (arr != nullptr) {
    delete[] arr;
}
```

Перед завершением программы нужно освободить память, если массив не пуст. Это защита от утечки памяти.

## Пример работы программы (детально)

Допустим, пользователь выполняет следующие действия:
1. Добавить числа 10, 20, 30
2. Показать массив
3. Вставить число 15 на позицию 2
4. Удалить элемент номер 4
5. Удалить элемент со значением 10
6. Показать массив
7. Очистить массив
8. Выйти

**Шаг за шагом:**

1. **Добавить 10:**
   - size = 0 → size = 1
   - arr = [10]

2. **Добавить 20:**
   - size = 1 → size = 2
   - arr = [10, 20]

3. **Добавить 30:**
   - size = 2 → size = 3
   - arr = [10, 20, 30]

4. **Показать массив:**
   - Вывод: "Массив: 10 20 30"

5. **Вставить 15 на позицию 2:**
   - index = 1
   - Копируем до индекса 1: [10]
   - Вставляем: [10, 15]
   - Копируем после: [10, 15, 20, 30]
   - size = 3 → size = 4
   - arr = [10, 15, 20, 30]

6. **Удалить элемент номер 4:**
   - index = 3
   - Копируем до индекса 3: [10, 15, 20]
   - После индекса 3 элементов нет
   - size = 4 → size = 3
   - arr = [10, 15, 20]

7. **Удалить элемент со значением 10:**
   - Ищем 10: найден на индексе 0
   - Копируем до индекса 0: (ничего)
   - Копируем после: [15, 20]
   - size = 3 → size = 2
   - arr = [15, 20]

8. **Показать массив:**
   - Вывод: "Массив: 15 20"

9. **Очистить массив:**
   - delete[] arr
   - arr = nullptr
   - size = 0

10. **Выйти:**
    - break - выход из цикла
    - arr == nullptr, поэтому delete[] не вызывается
    - return 0 - программа завершается

## Используемые концепции C++

### 1. nullptr - пустой указатель
```cpp
int* arr = nullptr;
```

`nullptr` означает "указатель ни на что". Это безопаснее, чем не инициализировать указатель.

### 2. Проверка указателя перед удалением
```cpp
if (arr != nullptr) {
    delete[] arr;
}
```

Нельзя удалять `nullptr` - это вызовет ошибку.

### 3. Обнуление указателя после удаления
```cpp
delete[] arr;
arr = nullptr;
```

После удаления массива нужно обнулить указатель, чтобы программа "забыла" про него.

### 4. Бесконечный цикл с выходом по условию
```cpp
while (true) {
    // код
    if (условие_выхода) {
        break;
    }
}
```

Цикл выполняется бесконечно, пока не будет выполнен `break`.

### 5. Длинная цепочка if-else
```cpp
if (choice == 0) { ... }
else if (choice == 1) { ... }
else if (choice == 2) { ... }
// ...
else { ... }
```

Когда вариантов много, лучше использовать `switch`, но `if-else` тоже работает.

## Ограничения программы

1. **Нет проверки ввода** - если ввести букву вместо числа, программа может сломаться
2. **Всё в main** - код очень длинный и сложный для чтения
3. **Нет сохранения** - нельзя сохранить массив в файл
4. **Нет загрузки** - нельзя загрузить массив из файла
5. **Удаляет только первое вхождение** - если в массиве несколько одинаковых элементов, удалится только первый

## Частые ошибки новичков

### Ошибка 1: Забыли проверить nullptr перед удалением
```cpp
// НЕПРАВИЛЬНО:
int* arr = nullptr;
delete[] arr;  // ошибка! нельзя удалять nullptr

// ПРАВИЛЬНО:
int* arr = nullptr;
if (arr != nullptr) {
    delete[] arr;
}
```

### Ошибка 2: Забыли обнулить указатель после удаления
```cpp
// НЕПРАВИЛЬНО:
delete[] arr;
// arr всё ещё указывает на удалённую память!
// если попытаться использовать arr, будет ошибка

// ПРАВИЛЬНО:
delete[] arr;
arr = nullptr;  // обнуляем указатель
```

### Ошибка 3: Не освободили память перед завершением
```cpp
// НЕПРАВИЛЬНО:
int* arr = new int[10];
// используем arr
return 0;  // память не освобождена!

// ПРАВИЛЬНО:
int* arr = new int[10];
// используем arr
delete[] arr;  // освобождаем память
return 0;
```

### Ошибка 4: Попытка удалить из пустого массива
```cpp
// НЕПРАВИЛЬНО:
int size = 0;
int* arr = nullptr;
// пытаемся удалить элемент - ошибка!

// ПРАВИЛЬНО:
if (size == 0) {
    cout << "Массив пуст!" << endl;
}
else {
    // удаляем элемент
}
```

### Ошибка 5: Забыли обновить size после операции
```cpp
// НЕПРАВИЛЬНО:
arr = newArr;
// size не обновлён!

// ПРАВИЛЬНО:
arr = newArr;
size = newSize;  // обновляем размер
```

## Итог

Эта программа демонстрирует все основные концепции работы с динамическими массивами в C++:
- **Динамическое выделение памяти** - создание массивов во время работы программы
- **Управление памятью** - обязательное освобождение памяти через delete[]
- **nullptr** - безопасная работа с пустыми указателями
- **Копирование массивов** - перенос данных между массивами
- **Сдвиг элементов** - при вставке и удалении
- **Линейный поиск** - поиск элемента по значению
- **Циклическая работа** - программа работает, пока пользователь не выйдет
- **Меню** - удобный интерфейс для пользователя

Эта программа - основа для понимания более сложных структур данных, таких как `std::vector`, который делает всё это автоматически.
