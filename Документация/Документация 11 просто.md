# Документация 11: «Сложение двух матриц» (Простой вариант)

## README.md

### Что это за программа
Это программа на C++, которая работает с двумя матрицами одинакового размера. Она:
- Запрашивает у пользователя размеры матриц (N строк, M столбцов)
- Позволяет заполнить **две матрицы** числами
- Выводит обе исходные матрицы на экран
- **Складывает** их поэлементно
- Выводит результат сложения на экран

**Главная особенность:** программа работает с **тремя матрицами одновременно** — двумя исходными и одной результирующей.

### Что такое сложение матриц?
Сложение матриц — это операция, при которой:
- Складываются **только матрицы одинакового размера**
- Каждый элемент результата равен **сумме соответствующих элементов** исходных матриц
- Формула: `C[i][j] = A[i][j] + B[i][j]`

Визуально:
```
Матрица A:     Матрица B:     Результат C:
1  2  3        9  8  7        10 10 10
4  5  6   +    6  5  4   =    10 10 10
7  8  9        3  2  1        10 10 10
```

**Важно:** размеры матриц **не меняются**. Если A и B имеют размер N×M, то и C будет N×M.

### Как работает программа (пошагово)

#### Шаг 1: Запрос размеров матрицы
```cpp
int n, m;
cout << "Введите количество строк: ";
cin >> n;
cout << "Введите количество столбцов: ";
cin >> m;
```
Создаём две переменные:
- `n` — количество строк
- `m` — количество столбцов

**Почему один размер для обеих матриц?**
Потому что сложить можно только матрицы **одинакового размера**. Если размеры разные — операция невозможна.

#### Шаг 2: Проверка размеров
```cpp
if (n < 1 || n > 10 || m < 1 || m > 10) {
    cout << "Ошибка: размеры должны быть от 1 до 10!" << endl;
    return 1;
}
```
Проверяем оба размера.

#### Шаг 3: Создание трёх матриц
```cpp
int a[10][10];   // первая матрица
int b[10][10];   // вторая матрица
int c[10][10];   // результат сложения
```
**Почему три матрицы?**
- `a` — первая исходная матрица
- `b` — вторая исходная матрица
- `c` — результат, куда будем складывать

Можно ли обойтись двумя? Можно, если хранить результат в `a` или `b`, но тогда мы потеряем исходные данные. Лучше иметь три матрицы — так нагляднее.

#### Шаг 4: Заполнение матрицы A
```cpp
cout << "\nВведите матрицу A (" << n << "x" << m << "):" << endl;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cin >> a[i][j];
    }
}
```
Проходим по всем элементам матрицы A и заполняем её.

#### Шаг 5: Заполнение матрицы B
```cpp
cout << "\nВведите матрицу B (" << n << "x" << m << "):" << endl;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cin >> b[i][j];
    }
}
```
Аналогично заполняем матрицу B.

#### Шаг 6: Сложение матриц — ключевая операция
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        c[i][j] = a[i][j] + b[i][j];
    }
}
```

**Что здесь происходит?**
Это самая простая часть задачи! Разберём формулу:

- Проходим по всем элементам матриц
- Для каждой позиции `(i, j)` берём элемент из `a` и элемент из `b`
- Складываем их и кладём результат в `c`

**Пример для матрицы 2×2:**
```
a:           b:           c:
1  2         9  8         10 10
3  4         7  6         10 10

c[0][0] = a[0][0] + b[0][0] = 1 + 9 = 10
c[0][1] = a[0][1] + b[0][1] = 2 + 8 = 10
c[1][0] = a[1][0] + b[1][0] = 3 + 7 = 10
c[1][1] = a[1][1] + b[1][1] = 4 + 6 = 10
```

#### Шаг 7: Вывод всех трёх матриц
```cpp
cout << "\nМатрица A:" << endl;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cout << a[i][j] << "\t";
    }
    cout << endl;
}

cout << "\nМатрица B:" << endl;
// аналогично

cout << "\nРезультат (A + B):" << endl;
// аналогично для c
```
Выводим все три матрицы, чтобы было видно, что сложение прошло правильно.

### Используемые концепции C++

#### 1. Несколько двумерных массивов
```cpp
int a[10][10];
int b[10][10];
int c[10][10];
```
Три матрицы работают параллельно.

#### 2. Параллельный обход нескольких массивов
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        c[i][j] = a[i][j] + b[i][j];
    }
}
```
Один цикл обрабатывает сразу три массива.

#### 3. Поэлементные операции
Каждый элемент результата вычисляется независимо от других.

### Пример работы программы (детально)

Допустим, пользователь вводит:
- Строки: 2
- Столбцы: 3
- Матрица A:
  ```
  1  2  3
  4  5  6
  ```
- Матрица B:
  ```
  9  8  7
  6  5  4
  ```

**Что происходит в памяти:**

1. Создаются переменные:
   ```
   n = 2
   m = 3
   ```

2. Создаются три матрицы 10×10 (используем только 2×3 часть):
   ```
   a:
   [1] [2] [3]  [0] [0] ...
   [4] [5] [6]  [0] [0] ...

   b:
   [9] [8] [7]  [0] [0] ...
   [6] [5] [4]  [0] [0] ...

   c:
   [0] [0] [0] ...
   [0] [0] [0] ...
   ```

3. Выполняется сложение:
   ```
   i=0, j=0: c[0][0] = a[0][0] + b[0][0] = 1 + 9 = 10
   i=0, j=1: c[0][1] = a[0][1] + b[0][1] = 2 + 8 = 10
   i=0, j=2: c[0][2] = a[0][2] + b[0][2] = 3 + 7 = 10
   i=1, j=0: c[1][0] = a[1][0] + b[1][0] = 4 + 6 = 10
   i=1, j=1: c[1][1] = a[1][1] + b[1][1] = 5 + 5 = 10
   i=1, j=2: c[1][2] = a[1][2] + b[1][2] = 6 + 4 = 10
   ```

4. Результат в c:
   ```
   [10] [10] [10]
   [10] [10] [10]
   ```

### Ограничения программы
- **Всё в main** — код не разбит на функции
- **Нет проверки ввода** — если ввести букву, программа может работать неправильно
- **Работает один раз** — чтобы обработать другие матрицы, нужно запустить заново
- **Ограниченный размер** — максимум 10×10
- **Нет проверки совпадения размеров** — предполагается, что пользователь вводит одинаковые размеры

### Что можно улучшить
- Разбить код на функции (ввод, вывод, сложение)
- Добавить проверку ввода
- Сделать цикл для многократной работы
- Добавить проверку, что размеры матриц совпадают
- Использовать динамические массивы для матриц любого размера
- Добавить вычитание матриц
- Добавить умножение матриц (более сложная операция)

### Частые ошибки новичков

#### Ошибка 1: Сложение матриц разного размера
```cpp
// НЕПРАВИЛЬНО:
int a[3][3], b[2][4];
// Нельзя сложить матрицы разного размера!

// ПРАВИЛЬНО:
int a[3][3], b[3][3];
// Размеры должны совпадать
```

#### Ошибка 2: Неверная формула сложения
```cpp
// НЕПРАВИЛЬНО:
c[i][j] = a[j][i] + b[i][j];  // перепутали индексы!

// ПРАВИЛЬНО:
c[i][j] = a[i][j] + b[i][j];  // одинаковые индексы
```

#### Ошибка 3: Забыли инициализировать матрицу C
```cpp
// НЕПРАВИЛЬНО:
int c[10][10];  // содержит мусор!
// Если не все элементы будут заполнены, в выводе будет мусор

// ПРАВИЛЬНО:
int c[10][10] = {0};  // инициализируем нулями
// Или гарантируем, что все элементы будут заполнены в цикле
```

#### Ошибка 4: Вывод только результата, без исходных матриц
```cpp
// НЕПРАВИЛЬНО (с точки зрения наглядности):
// Выводим только C
// Пользователь не видит, что было сложено

// ПРАВИЛЬНО:
// Выводим A, B и C
// Видно всю картину
```

#### Ошибка 5: Использование одной матрицы для двух целей
```cpp
// НЕПРАВИЛЬНО:
int matrix[10][10];
// Ввели A
// Ввели B (перезаписали A!)
// Теперь A потеряна

// ПРАВИЛЬНО:
int a[10][10], b[10][10], c[10][10];
// Три отдельные матрицы
```

### Итог
Эта программа демонстрирует:
- **Работу с несколькими матрицами** — параллельная обработка
- **Поэлементные операции** — одинаковые индексы для всех матриц
- **Параллельный обход** — один цикл для нескольких массивов
- **Понимание ограничений** — сложение только для матриц одинакового размера

Программа простая, но даёт понимание базовых операций с матрицами, которые используются в математике, графике и машинном обучении.
