# Создание и анализ матрицы - Документация (Улучшенный вариант)

## Что это за программа

Улучшенная версия программы для анализа матрицы. Основные улучшения:
- **Код разбит на функции** - каждая функция выполняет одну задачу
- **Проверка ввода** - защита от некорректного ввода
- **Отдельные функции для создания и удаления матрицы** - удобство работы с памятью
- **Проверка размеров с повторным запросом** - пользователь не сможет ввести неправильный размер

## Главное отличие от простой версии

**Простая версия:**
- Весь код в main() - около 90 строк
- Нет проверки ввода
- Сложно читать и поддерживать

**Улучшенная версия:**
- Код разбит на 10 функций
- Проверка ввода с очисткой потока
- Каждая функция выполняет одну задачу
- Легко читать и поддерживать

## Как работает программа (пошагово)

### Шаг 1: Функция createMatrix - создание матрицы

```cpp
int** createMatrix(int rows, int cols) {
    int** matrix = new int*[rows];
    for (int i = 0; i < rows; i++) {
        matrix[i] = new int[cols];
    }
    return matrix;
}
```

**Что здесь особенного?**

Функция создаёт матрицу в динамической памяти и возвращает указатель на неё. Это удобно - вызывающий код не должен знать, как именно создаётся матрица.

### Шаг 2: Функция deleteMatrix - освобождение памяти

```cpp
void deleteMatrix(int** matrix, int rows) {
    for (int i = 0; i < rows; i++) {
        delete[] matrix[i];
    }
    delete[] matrix;
}
```

**Зачем отдельная функция?**
Чтобы не забывать освобождать память. Вызвал `createMatrix` - вызови `deleteMatrix`.

### Шаг 3: Функция countEvenOdd - подсчёт чётных и нечётных

```cpp
void countEvenOdd(int** matrix, int rows, int cols, int& evenCount, int& oddCount) {
    evenCount = 0;
    oddCount = 0;
    
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (matrix[i][j] % 2 == 0) {
                evenCount++;
            }
            else {
                oddCount++;
            }
        }
    }
}
```

**Что здесь особенного?**

Функция возвращает **два значения** через параметры-ссылки (`int& evenCount`, `int& oddCount`). Это позволяет изменить значения переменных в вызывающем коде.

### Шаг 4: Проверка размеров с повторным запросом

```cpp
do {
    rows = inputNumber("Введите количество строк (1-10): ");
    if (rows < 1 || rows > 10) {
        cout << "Ошибка: количество строк должно быть от 1 до 10!" << endl;
    }
} while (rows < 1 || rows > 10);
```

**Цикл do-while:**
- Сначала выполняет код
- Потом проверяет условие
- Если условие истинно - повторяет

Это гарантирует, что пользователь введёт правильный размер, прежде чем программа продолжит работу.

## Используемые концепции C++

### 1. Функции, возвращающие указатели
```cpp
int** createMatrix(int rows, int cols);
```

### 2. Передача по ссылке для возврата нескольких значений
```cpp
void countEvenOdd(int** matrix, int rows, int cols, int& evenCount, int& oddCount);
```

### 3. Цикл do-while
```cpp
do {
    // код
} while (условие);
```

### 4. Параметры по умолчанию
```cpp
void printMatrix(int** matrix, int rows, int cols, const string& label = "");
```

### 5. Разделение ответственности
Каждая функция выполняет одну задачу.

## Итог

Эта программа демонстрирует продвинутые концепции C++:
- **Функции для работы с матрицами** - создание, заполнение, вывод, удаление
- **Вложенные циклы** - обход всех элементов матрицы
- **Передача по ссылке** - возврат нескольких значений из функции
- **Цикл do-while** - повторный запрос при ошибке
- **Разделение ответственности** - каждая функция делает одно дело
