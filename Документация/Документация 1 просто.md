# Простой калькулятор - Документация

## Что это за программа

Это базовая программа на C++, которая выполняет роль простого калькулятора. Она спрашивает у пользователя два числа и операцию, которую нужно выполнить, а затем показывает результат.

Программа работает **один раз** - после выполнения операции она завершается.

## Как работает программа (пошагово)

### Шаг 1: Подготовка переменных
```cpp
double num1, num2;
char operation;
```
Программа создаёт три "коробочки" в памяти:
- `num1` - для первого числа (тип `double` - дробное число)
- `num2` - для второго числа (тоже `double`)
- `operation` - для символа операции (тип `char` - один символ)

**Почему `double`, а не `int`?**
Потому что мы хотим работать с дробными числами. Если использовать `int`, то 5 / 2 даст 2, а не 2.5.

### Шаг 2: Ввод данных от пользователя
```cpp
cout << "Введите первое число: ";
cin >> num1;
```
- `cout` - выводит текст на экран
- `cin` - читает то, что вводит пользователь
- `>>` - оператор "стрелка вправо", означает "положить введённое значение в переменную"

Программа по очереди спрашивает:
1. Первое число → кладёт в `num1`
2. Второе число → кладёт в `num2`
3. Операцию → кладёт в `operation`

### Шаг 3: Проверка операции через if-else
```cpp
if (operation == '+') {
    cout << "Результат: " << num1 + num2 << endl;
}
else if (operation == '-') {
    cout << "Результат: " << num1 - num2 << endl;
}
```

**Как это работает:**
1. Программа проверяет: "А что в переменной `operation`?"
2. Если там `+` → складывает числа и выводит результат
3. Если там не `+`, но есть `-` → вычитает
4. Если там не `+` и не `-`, но есть `*` → умножает
5. И так далее...
6. Если ничего не подошло → выводит ошибку

**Важно:** программа проверяет условия **по порядку** и останавливается на первом подходящем.

### Шаг 4: Особый случай - деление на ноль
```cpp
else if (operation == '/') {
    if (num2 == 0) {
        cout << "Ошибка: деление на ноль!" << endl;
    }
    else {
        cout << "Результат: " << num1 / num2 << endl;
    }
}
```

**Почему нужна проверка?**
Деление на ноль в математике невозможно. Если мы попробуем поделить на ноль, программа может:
- Выдать ошибку
- Зависнуть
- Дать неправильный результат

Поэтому мы **сначала проверяем**, не равен ли `num2` нулю, и только потом делим.

**Вложенный if:**
Обратите внимание, что внутри проверки на деление есть **ещё одна проверка** (вложенный if). Это нормально - проверки могут быть внутри других проверок.

## Используемые концепции C++

### 1. Переменные
```cpp
double num1;  // дробное число
char operation;  // один символ
```
Переменная - это именованная ячейка памяти. Мы даём ей имя и тип, чтобы программа знала, сколько памяти выделить и как интерпретировать данные.

### 2. Ввод/вывод (iostream)
```cpp
#include <iostream>  // подключаем библиотеку ввода/вывода
cout << "текст";     // вывод на экран
cin >> переменная;   // ввод с клавиатуры
```

### 3. Условные операторы (if-else)
```cpp
if (условие) {
    // код, если условие истинно
}
else if (другое условие) {
    // код, если первое условие ложно, но второе истинно
}
else {
    // код, если все условия ложны
}
```

### 4. Операции сравнения
```cpp
operation == '+'  // равно ли operation символу '+'?
num2 == 0         // равно ли num2 нулю?
```
**Важно:** `==` - это сравнение, а `=` - это присваивание. Не путайте!

## Пример работы программы (детально)

Допустим, пользователь вводит:
- Первое число: 10
- Второе число: 5
- Операция: *

**Что происходит в памяти:**

1. Создаются переменные:
   ```
   num1 = ? (пусто)
   num2 = ? (пусто)
   operation = ? (пусто)
   ```

2. Пользователь вводит 10:
   ```
   num1 = 10.0
   num2 = ? (пусто)
   operation = ? (пусто)
   ```

3. Пользователь вводит 5:
   ```
   num1 = 10.0
   num2 = 5.0
   operation = ? (пусто)
   ```

4. Пользователь вводит *:
   ```
   num1 = 10.0
   num2 = 5.0
   operation = '*'
   ```

5. Программа проверяет:
   - `operation == '+'`? Нет (там '*')
   - `operation == '-'`? Нет (там '*')
   - `operation == '*'`? Да! → выполняем `num1 * num2`

6. Вычисляем: `10.0 * 5.0 = 50.0`

7. Выводим: "Результат: 50"

8. Завершаем программу: `return 0;`

## Ограничения программы

1. **Работает только один раз** - после выполнения операции программа завершается
2. **Нет проверки ввода** - если ввести букву вместо числа, программа может работать неправильно
3. **Ограниченный набор операций** - только +, -, *, /
4. **Нет истории вычислений** - нельзя использовать результат предыдущей операции

## Частые ошибки новичков

### Ошибка 1: Путаница между = и ==
```cpp
// НЕПРАВИЛЬНО:
if (operation = '+')  // это присваивание, а не сравнение!

// ПРАВИЛЬНО:
if (operation == '+')  // это сравнение
```

### Ошибка 2: Забыли проверить деление на ноль
```cpp
// НЕПРАВИЛЬНО:
if (operation == '/') {
    cout << num1 / num2 << endl;  // а если num2 == 0?
}

// ПРАВИЛЬНО:
if (operation == '/') {
    if (num2 == 0) {
        cout << "Ошибка!" << endl;
    } else {
        cout << num1 / num2 << endl;
    }
}
```

### Ошибка 3: Неверный порядок проверок
```cpp
// НЕПРАВИЛЬНО:
if (operation == '/') {
    cout << num1 / num2 << endl;
}
else if (operation == '/') {  // эта проверка никогда не сработает!
    if (num2 == 0) {
        cout << "Ошибка!" << endl;
    }
}

// ПРАВИЛЬНО:
if (operation == '/') {
    if (num2 == 0) {
        cout << "Ошибка!" << endl;
    } else {
        cout << num1 / num2 << endl;
    }
}
```
