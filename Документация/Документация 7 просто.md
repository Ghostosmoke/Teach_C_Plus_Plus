# Создание и анализ матрицы - Документация (Простой вариант)

## Что это за программа

Программа создаёт двумерный массив (матрицу) размером N×M, заполняет его числами от пользователя, а затем анализирует:
- Выводит матрицу в виде таблицы
- Считает сумму всех элементов
- Находит максимальный и минимальный элементы
- Считает количество чётных и нечётных элементов

**Главная особенность:** матрица - это **двумерный** массив, то есть массив массивов. Чтобы обратиться к элементу, нужно указать **два индекса**: номер строки и номер столбца.

## Что такое матрица?

Матрица - это таблица чисел. Например:
```
1   2   3
4   5   6
7   8   9
```

Это матрица 3×3 (3 строки, 3 столбца).

**Как обратиться к элементу:**
- `matrix[0][0]` = 1 (первая строка, первый столбец)
- `matrix[0][2]` = 3 (первая строка, третий столбец)
- `matrix[2][1]` = 8 (третья строка, второй столбец)

**Важно:** индексы начинаются с 0!

## Как работает программа (пошагово)

### Шаг 1: Запрос размеров матрицы
```cpp
int rows, cols;
cout << "Введите количество строк: ";
cin >> rows;
cout << "Введите количество столбцов: ";
cin >> cols;
```

Спрашиваем у пользователя, сколько строк и столбцов будет в матрице.

### Шаг 2: Создание динамической матрицы
```cpp
int** matrix = new int*[rows];

for (int i = 0; i < rows; i++) {
    matrix[i] = new int[cols];
}
```

**Что здесь происходит?**

Матрица в C++ - это **массив указателей**. Каждый указатель ведёт на строку матрицы.

```
matrix → [указатель 0] → [строка 0: 1  2  3]
         [указатель 1] → [строка 1: 4  5  6]
         [указатель 2] → [строка 2: 7  8  9]
```

**Почему `int**`?**
- `int*` - указатель на int (одномерный массив)
- `int**` - указатель на указатель на int (двумерный массив)

**Как это работает:**
1. `new int*[rows]` - создаём массив из `rows` указателей
2. Для каждого указателя `matrix[i]` выделяем память под `cols` целых чисел

### Шаг 3: Заполнение матрицы
```cpp
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        cout << "Элемент [" << i << "][" << j << "]: ";
        cin >> matrix[i][j];
    }
}
```

**Два вложенных цикла:**
- Внешний цикл (`i`) проходит по строкам
- Внутренний цикл (`j`) проходит по столбцам

**Порядок заполнения:**
```
i=0, j=0 → matrix[0][0]  (первая строка, первый столбец)
i=0, j=1 → matrix[0][1]  (первая строка, второй столбец)
i=0, j=2 → matrix[0][2]  (первая строка, третий столбец)
i=1, j=0 → matrix[1][0]  (вторая строка, первый столбец)
...
```

### Шаг 4: Вывод матрицы
```cpp
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        cout << matrix[i][j] << "\t";
    }
    cout << endl;
}
```

**`\t` - это табуляция** (отступ), чтобы числа выравнивались в столбцы.

**`endl` после внутреннего цикла** - переход на новую строку после каждой строки матрицы.

### Шаг 5: Сумма всех элементов
```cpp
int sum = 0;
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        sum += matrix[i][j];
    }
}
```

Проходим по всем элементам матрицы и добавляем каждый к сумме.

### Шаг 6: Поиск максимума и минимума
```cpp
int max = matrix[0][0];
int min = matrix[0][0];

for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        if (matrix[i][j] > max) {
            max = matrix[i][j];
        }
        if (matrix[i][j] < min) {
            min = matrix[i][j];
        }
    }
}
```

**Алгоритм:**
1. Предполагаем, что первый элемент - и максимум, и минимум
2. Проходим по всем элементам
3. Если нашли элемент больше текущего максимума - обновляем максимум
4. Если нашли элемент меньше текущего минимума - обновляем минимум

### Шаг 7: Подсчёт чётных и нечётных
```cpp
int evenCount = 0;
int oddCount = 0;

for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        if (matrix[i][j] % 2 == 0) {
            evenCount++;
        }
        else {
            oddCount++;
        }
    }
}
```

**`% 2` - это остаток от деления на 2:**
- Если остаток 0 - число чётное
- Если остаток 1 - число нечётное

### Шаг 8: Освобождение памяти
```cpp
for (int i = 0; i < rows; i++) {
    delete[] matrix[i];
}
delete[] matrix;
```

**Важно:** для двумерного динамического массива нужно:
1. Сначала удалить каждую строку: `delete[] matrix[i]`
2. Потом удалить массив указателей: `delete[] matrix`

**Почему в таком порядке?**
Если сначала удалить `matrix`, мы потеряем адреса строк и не сможем их удалить - будет утечка памяти.

## Используемые концепции C++

### 1. Двумерные динамические массивы
```cpp
int** matrix = new int*[rows];
for (int i = 0; i < rows; i++) {
    matrix[i] = new int[cols];
}
```

### 2. Доступ к элементам матрицы
```cpp
matrix[i][j]  // элемент в строке i, столбце j
```

### 3. Вложенные циклы
```cpp
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        // код
    }
}
```

### 4. Остаток от деления
```cpp
if (x % 2 == 0) {
    // x чётное
}
```

### 5. Освобождение двумерного массива
```cpp
for (int i = 0; i < rows; i++) {
    delete[] matrix[i];
}
delete[] matrix;
```

## Частые ошибки новичков

### Ошибка 1: Забыли удалить строки перед удалением матрицы
```cpp
// НЕПРАВИЛЬНО:
delete[] matrix;  // утечка памяти! строки не удалены

// ПРАВИЛЬНО:
for (int i = 0; i < rows; i++) {
    delete[] matrix[i];  // сначала удаляем строки
}
delete[] matrix;  // потом удаляем массив указателей
```

### Ошибка 2: Выход за границы матрицы
```cpp
// НЕПРАВИЛЬНО:
matrix[rows][cols] = 10;  // ошибка! индексы от 0 до rows-1 и cols-1

// ПРАВИЛЬНО:
matrix[rows-1][cols-1] = 10;  // последний элемент
```

### Ошибка 3: Перепутали строки и столбцы
```cpp
// НЕПРАВИЛЬНО:
for (int j = 0; j < cols; j++) {
    for (int i = 0; i < rows; i++) {  // странная_order_
        // ...
    }
}

// ПРАВИЛЬНО:
for (int i = 0; i < rows; i++) {  // сначала строки
    for (int j = 0; j < cols; j++) {  // потом столбцы
        // ...
    }
}
```

### Ошибка 4: Инициализация максимума нулём
```cpp
// НЕПРАВИЛЬНО:
int max = 0;  // а если все числа отрицательные?

// ПРАВИЛЬНО:
int max = matrix[0][0];  // берём первый элемент
```

- **Двумерные динамические массивы** - создание матрицы в памяти
- **Вложенные циклы** - обход всех элементов матрицы
