
# Документация 10: «Поворот матрицы на 90 градусов» (Улучшенный вариант)

## README.md

### Что это за программа
Улучшенная версия программы для поворота матрицы на 90 градусов. Основные улучшения:
- **Код разбит на функции** — каждая функция выполняет одну задачу
- **Проверка ввода** — защита от некорректного ввода пользователя
- **Циклическая работа** — можно обработать несколько матриц без перезапуска
- **Константные параметры** — защита данных от случайного изменения
- **Красивое оформление** — заголовки, разделители, подсказки

### Главное отличие от простой версии

**Простая версия:**
- Весь код в `main()` — сложно читать и поддерживать
- Нет проверки ввода
- Работает один раз

**Улучшенная версия:**
- Код разбит на 5 функций
- Проверка ввода с очисткой потока
- Работает циклически
- Константные параметры в функциях

### Как работает программа (пошагово)

#### Шаг 1: Функция inputSize — ввод размера с проверкой
```cpp
int inputSize() {
    int n;
    while (true) {
        cout << "Введите размер матрицы (1-10): ";
        cin >> n;
        
        if (cin.fail()) {
            cin.clear();
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            cout << "Ошибка: введите число!" << endl;
            continue;
        }
        
        if (n >= 1 && n <= 10) {
            break;
        }
        
        cout << "Ошибка: размер должен быть от 1 до 10!" << endl;
    }
    return n;
}
```

**Проверка `cin.fail()`**
Если пользователь ввёл букву вместо числа, `cin.fail()` возвращает `true`. Очищаем поток и просим ввести снова.

#### Шаг 2: Функция fillMatrix — заполнение матрицы
```cpp
void fillMatrix(int matrix[][10], int n) {
    cout << "Введите элементы матрицы (" << n << "x" << n << "):" << endl;
    for (int i = 0; i < n; i++) {
        cout << "Строка " << (i + 1) << ": ";
        for (int j = 0; j < n; j++) {
            cin >> matrix[i][j];
        }
    }
}
```

**Подсказка "Строка N:"**
Помогает пользователю понять, какую строку он сейчас заполняет.

#### Шаг 3: Функция printMatrix — вывод матрицы
```cpp
void printMatrix(const int matrix[][10], int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cout << matrix[i][j] << "\t";
        }
        cout << endl;
    }
}
```

**Почему `const int matrix[][10]`?**
- `const` — обещание не изменять матрицу
- Функция только читает данные, не изменяет их

#### Шаг 4: Функция rotateMatrix — поворот матрицы
```cpp
void rotateMatrix(const int source[][10], int result[][10], int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            result[j][n - 1 - i] = source[i][j];
        }
    }
}
```

**Почему `source` — const, а `result` — нет?**
- `source` — исходная матрица, её не меняем
- `result` — матрица результата, её заполняем

**Формула поворота:**
```cpp
result[j][n - 1 - i] = source[i][j];
```
Это и есть поворот на 90° по часовой стрелке.

#### Шаг 5: Функция processMatrix — обработка одной матрицы
```cpp
void processMatrix() {
    int n = inputSize();
    
    int matrix[10][10];
    int result[10][10];
    
    fillMatrix(matrix, n);
    
    cout << "\nИсходная матрица:" << endl;
    printMatrix(matrix, n);
    
    rotateMatrix(matrix, result, n);
    
    cout << "\nПосле поворота на 90 градусов по часовой стрелке:" << endl;
    printMatrix(result, n);
}
```

**Что делает эта функция?**
Это "оркестратор" — она координирует работу всех остальных функций.

#### Шаг 6: Главный цикл в main
```cpp
int main() {
    setlocale(LC_ALL, "Russian");
    
    cout << "=== Поворот матрицы на 90 градусов ===" << endl;
    
    while (true) {
        processMatrix();
        
        cout << "\nХотите обработать ещё одну матрицу? (1 - да, 0 - нет): ";
        int choice;
        cin >> choice;
        
        if (choice == 0) {
            cout << "До свидания!" << endl;
            break;
        }
    }
    
    return 0;
}
```

### Поток выполнения программы (детально)

Допустим, пользователь хочет:
1. Повернуть матрицу 3×3: `1 2 3 / 4 5 6 / 7 8 9`
2. Повернуть матрицу 2×2: `10 20 / 30 40`
3. Выйти

**Первая итерация:**
1. `main()` вызывает `processMatrix()`
2. `processMatrix()` вызывает `inputSize()`
3. Пользователь вводит `3`
4. `inputSize()` возвращает `3`
5. `processMatrix()` создаёт две матрицы
6. `processMatrix()` вызывает `fillMatrix(matrix, 3)`
7. Пользователь вводит: `1 2 3 4 5 6 7 8 9`
8. `processMatrix()` вызывает `printMatrix(matrix, 3)`
9. Выводится исходная матрица
10. `processMatrix()` вызывает `rotateMatrix(matrix, result, 3)`
11. Внутри `rotateMatrix`:
    ```
    i=0, j=0: result[0][2] = matrix[0][0] = 1
    i=0, j=1: result[1][2] = matrix[0][1] = 2
    i=0, j=2: result[2][2] = matrix[0][2] = 3
    i=1, j=0: result[0][1] = matrix[1][0] = 4
    i=1, j=1: result[1][1] = matrix[1][1] = 5
    i=1, j=2: result[2][1] = matrix[1][2] = 6
    i=2, j=0: result[0][0] = matrix[2][0] = 7
    i=2, j=1: result[1][0] = matrix[2][1] = 8
    i=2, j=2: result[2][0] = matrix[2][2] = 9
    ```
12. `processMatrix()` вызывает `printMatrix(result, 3)`
13. Выводится повёрнутая матрица:
    ```
    7  4  1
    8  5  2
    9  6  3
    ```
14. `main()` спрашивает: "Продолжить?"
15. Пользователь вводит `1`
16. Цикл продолжается

**Вторая итерация:**
- Аналогично, но с матрицей 2×2
- Результат — повёрнутая матрица 2×2

**Третья итерация:**
- Пользователь вводит `0`
- `break` — выход из цикла
- Вывод: "До свидания!"
- `return 0` — программа завершается

### Используемые концепции C++

#### 1. Функции с разными типами возврата
```cpp
int inputSize();           // возвращает int
void fillMatrix(...);      // ничего не возвращает
void printMatrix(...);     // ничего не возвращает
void rotateMatrix(...);    // ничего не возвращает
```

#### 2. Передача двумерных массивов в функции
```cpp
void fillMatrix(int matrix[][10], int n);
void printMatrix(const int matrix[][10], int n);
void rotateMatrix(const int source[][10], int result[][10], int n);
```

#### 3. Константные параметры
```cpp
void printMatrix(const int matrix[][10], int n);
void rotateMatrix(const int source[][10], int result[][10], int n);
```
`const` защищает данные от изменения.

#### 4. Разделение ответственности
Каждая функция выполняет одну задачу:
- `inputSize()` — ввод размера
- `fillMatrix()` — заполнение матрицы
- `printMatrix()` — вывод матрицы
- `rotateMatrix()` — поворот матрицы

### Пример работы программы (детально)

Допустим, пользователь вводит:
- Размер: 3
- Элементы:
  ```
  1  2  3

**Что происходит:**
1. `inputSize()` возвращает `n = 3`

   result[0][2] = 1, result[1][2] = 2, result[2][2] = 3

   ```

   ```
   7  4  1
   8  5  2
   9  6  3
   ```

### Ограничения программы
- **Ограниченный размер** — максимум 10×10
- **Нет rotate "на месте"** — для квадратных матриц можно было бы экономить память
- **Только поворот на 90°** — нет 180° и 270°
- **Нет сохранения результатов** — нельзя экспортировать в файл

### Что можно улучшить
- Для квадратных матриц делать rotate "на месте" (без второй матрицы)
- Добавить поворот на 180° и 270°
- Добавить другие операции с матрицами (транспонирование, отражение, умножение)
- Использовать динамические массивы для матриц любого размера
- Добавить возможность загрузки матрицы из файла
- Добавить визуализацию (анимацию поворота)

### Частые ошибки новичков

#### Ошибка 1: Забыли const в параметре функции
```cpp
// НЕПРАВИЛЬНО:
void printMatrix(int matrix[][10], int n);
// Функция может случайно изменить матрицу

// ПРАВИЛЬНО:
void printMatrix(const int matrix[][10], int n);
// Функция обещает не изменять матрицу
```

#### Ошибка 2: Неверная передача двумерного массива
```cpp
// НЕПРАВИЛЬНО:
void rotateMatrix(int matrix[][], int result[][], int n);  // не указан размер!

// ПРАВИЛЬНО:
void rotateMatrix(const int source[][10], int result[][10], int n);
```

#### Ошибка 3: Неверная формула поворота
```cpp
// НЕПРАВИЛЬНО:
result[i][j] = source[j][i];  // это транспонирование!

// ПРАВИЛЬНО:
result[j][n - 1 - i] = source[i][j];  // это поворот на 90°
```

#### Ошибка 4: Не очистили поток после ошибки ввода
```cpp
// НЕПРАВИЛЬНО:
cin >> n;
if (cin.fail()) {
    cout << "Ошибка!" << endl;
    // поток не очищен
}

// ПРАВИЛЬНО:
cin >> n;
if (cin.fail()) {
    cin.clear();
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    cout << "Ошибка!" << endl;
}
```

#### Ошибка 5: Попытка повернуть "на месте" без понимания
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        swap(matrix[i][j], matrix[j][n - 1 - i]);  // всё сломается!
    }
}

// ПРАВИЛЬНО:
// Используем вторую матрицу для результата
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        result[j][n - 1 - i] = matrix[i][j];
    }
}
```
