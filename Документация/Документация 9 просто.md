# Документация 9: «Транспонирование матрицы» (Простой вариант)

## README.md

### Что это за программа
Это программа на C++, которая работает с матрицей (двумерным массивом чисел). Она:
- Запрашивает у пользователя размеры матрицы (N строк, M столбцов)
- Позволяет заполнить матрицу числами
- Выводит исходную матрицу на экран
- **Транспонирует** матрицу — меняет местами строки и столбцы
- Выводит транспонированную матрицу на экран

**Главная особенность:** матрица создаётся **статически** - с фиксированным максимальным размером 10×10, а реальные размеры задаёт пользователь.

### Что такое транспонирование?
Транспонирование — это операция, при которой:
- Строки исходной матрицы становятся столбцами результата
- Столбцы исходной матрицы становятся строками результата
- Элемент `[i][j]` переходит в позицию `[j][i]`

Визуально:
```
Было (2×3):        Стало (3×2):
1  2  3            1  4
4  5  6            2  5
                   3  6
```

**Важно:** размер матрицы меняется! Было N×M → стало M×N.

### Как работает программа (пошагово)

#### Шаг 1: Запрос размеров матрицы
```cpp
int n, m;
cout << "Введите количество строк: ";
cin >> n;
cout << "Введите количество столбцов: ";
cin >> m;
```
Создаём две переменные:
- `n` — количество строк
- `m` — количество столбцов

**Почему два размера?**
В отличие от задачи с диагоналями, здесь матрица может быть **прямоугольной** (не обязательно квадратной). Транспонирование работает с любыми матрицами.

#### Шаг 2: Проверка размеров
```cpp
if (n < 1 || n > 10 || m < 1 || m > 10) {
    cout << "Ошибка: размеры должны быть от 1 до 10!" << endl;
    return 1;
}
```
Проверяем оба размера:
- Не меньше 1 — иначе матрица пустая
- Не больше 10 — иначе не поместится в статический массив

#### Шаг 3: Создание двух матриц
```cpp
int matrix[10][10];       // исходная матрица
int transposed[10][10];   // результат транспонирования
```
**Почему две матрицы?**
Потому что исходная матрица имеет размер N×M, а транспонированная — M×N. Они разного размера, поэтому нужны две разные матрицы.

**Можно ли сделать в одной матрице?**
Только если матрица **квадратная** (N = M). Для прямоугольной матрицы нужна отдельная матрица для результата.

#### Шаг 4: Заполнение исходной матрицы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cin >> matrix[i][j];
    }
}
```
Проходим по всем элементам матрицы:
- Внешний цикл — по строкам (от 0 до n-1)
- Внутренний цикл — по столбцам (от 0 до m-1)

#### Шаг 5: Вывод исходной матрицы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cout << matrix[i][j] << "\t";
    }
    cout << endl;
}
```
Выводим матрицу в виде таблицы. `\t` — табуляция для выравнивания столбцов.

#### Шаг 6: Транспонирование — ключевая операция
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        transposed[j][i] = matrix[i][j];
    }
}
```
**Что здесь происходит?**
- Проходим по всем элементам исходной матрицы
- Элемент `matrix[i][j]` (строка i, столбец j)
- Кладём в `transposed[j][i]` (строка j, столбец i)

**Индексы меняются местами!**

**Пример для матрицы 2×3:**
```
matrix[0][0] = 1  →  transposed[0][0] = 1
matrix[0][1] = 2  →  transposed[1][0] = 2
matrix[0][2] = 3  →  transposed[2][0] = 3
matrix[1][0] = 4  →  transposed[0][1] = 4
matrix[1][1] = 5  →  transposed[1][1] = 5
matrix[1][2] = 6  →  transposed[2][1] = 6
```

#### Шаг 7: Вывод транспонированной матрицы
```cpp
for (int i = 0; i < m; i++) {       // обратите внимание: i < m!
    for (int j = 0; j < n; j++) {   // и здесь: j < n!
        cout << transposed[i][j] << "\t";
    }
    cout << endl;
}
```
**Важный момент:**
- Теперь строк `m` (было столбцов)
- Теперь столбцов `n` (было строк)

Циклы идут до `m` и `n` соответственно, а не до `n` и `m` как раньше!

### Используемые концепции C++

#### 1. Двумерные массивы
```cpp
int matrix[10][10];       // 10 строк, 10 столбцов
int transposed[10][10];   // ещё одна матрица
```
Две матрицы — одна для исходных данных, другая для результата.

#### 2. Вложенные циклы
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        // код
    }
}
```
Цикл в цикле для перебора всех элементов матрицы.

#### 3. Обмен индексов
```cpp
transposed[j][i] = matrix[i][j];
```
Ключевая операция транспонирования — меняем местами индексы `i` и `j`.

#### 4. Разные размеры для разных матриц
- Исходная: `n` строк, `m` столбцов
- Транспонированная: `m` строк, `n` столбцов

### Пример работы программы (детально)

Допустим, пользователь вводит:
- Строки: 2
- Столбцы: 3
- Элементы:
  ```
  1  2  3
  4  5  6
  ```

**Что происходит в памяти:**

1. Создаются переменные:
   ```
   n = 2
   m = 3
   ```

2. Создаются две матрицы 10×10 (используем только нужные части):
   ```
   matrix:
   [1] [2] [3]  [0] [0] ...
   [4] [5] [6]  [0] [0] ...
   [0] [0] [0]  [0] [0] ...
   ...

   transposed:
   [0] [0] [0] ...
   [0] [0] [0] ...
   [0] [0] [0] ...
   ...
   ```

3. Выполняется транспонирование:
   ```
   i=0, j=0: transposed[0][0] = matrix[0][0] = 1
   i=0, j=1: transposed[1][0] = matrix[0][1] = 2
   i=0, j=2: transposed[2][0] = matrix[0][2] = 3
   i=1, j=0: transposed[0][1] = matrix[1][0] = 4
   i=1, j=1: transposed[1][1] = matrix[1][1] = 5
   i=1, j=2: transposed[2][1] = matrix[1][2] = 6
   ```

4. Результат в transposed:
   ```
   [1] [4] [0] ...
   [2] [5] [0] ...
   [3] [6] [0] ...
   ...
   ```

5. Выводим результат (циклы идут до m=3 и n=2):
   ```
   1  4
   2  5
   3  6
   ```

### Ограничения программы
- **Всё в main** — код не разбит на функции
- **Нет проверки ввода** — если ввести букву, программа может работать неправильно
- **Работает один раз** — чтобы обработать другую матрицу, нужно запустить заново
- **Ограниченный размер** — максимум 10×10
- **Только прямоугольные матрицы** — нельзя транспонировать "на месте" для квадратных

### Что можно улучшить
- Разбить код на функции (ввод, вывод, транспонирование)
- Добавить проверку ввода
- Сделать цикл для многократной работы
- Для квадратных матриц делать транспонирование "на месте" (без второй матрицы)
- Использовать динамические массивы для матриц любого размера

### Как скомпилировать и запустить
```bash
# Компиляция
g++ main.cpp -o transpose

# Запуск
```

### Частые ошибки новичков

#### Ошибка 1: Забыли поменять размеры при выводе результата
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < n; i++) {  // n — это строки исходной матрицы!
    for (int j = 0; j < m; j++) {  // m — это столбцы исходной матрицы!
        cout << transposed[i][j] << "\t";
    }
    cout << endl;
}
// Выведется только часть транспонированной матрицы!

// ПРАВИЛЬНО:
for (int i = 0; i < m; i++) {  // m строк в транспонированной матрице
    for (int j = 0; j < n; j++) {  // n столбцов в транспонированной матрице
        cout << transposed[i][j] << "\t";
    }
    cout << endl;
}
```

#### Ошибка 2: Неверная формула транспонирования
```cpp
// НЕПРАВИЛЬНО:
transposed[i][j] = matrix[i][j];  // это просто копирование!

// ПРАВИЛЬНО:
transposed[j][i] = matrix[i][j];  // индексы меняются местами!
```

#### Ошибка 3: Попытка транспонировать прямоугольную матрицу "на месте"
```cpp
// НЕПРАВИЛЬНО (для прямоугольной матрицы):
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        swap(matrix[i][j], matrix[j][i]);  // выход за границы!
    }
}
// Если n != m, то matrix[j][i] может выйти за границы массива!

// ПРАВИЛЬНО:
// Используем вторую матрицу для результата
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        transposed[j][i] = matrix[i][j];
    }
}
```

#### Ошибка 4: Двойной обмен при транспонировании квадратной матрицы
```cpp
// НЕПРАВИЛЬНО (для квадратной матрицы "на месте"):
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {  // проходим по ВСЕЙ матрице
        swap(matrix[i][j], matrix[j][i]);
    }
}
// Каждый элемент обменяется дважды — вернётся на своё место!

// ПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {  // только верхний треугольник!
        swap(matrix[i][j], matrix[j][i]);
    }
}
```

#### Ошибка 5: Путаница между строками и столбцами при вводе
```cpp
// НЕПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cin >> matrix[j][i];  // перепутали индексы!
    }
}
// Матрица будет заполнена транспонированной!

// ПРАВИЛЬНО:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cin >> matrix[i][j];  // сначала строка, потом столбец
    }
}
```

### Итог
Эта программа демонстрирует:
- **Работу с двумя матрицами** — исходной и результатом
- **Понимание размеров** — как меняются размеры при транспонировании
- **Обмен индексов** — ключевая операция `transposed[j][i] = matrix[i][j]`
- **Вложенные циклы** — для перебора всех элементов

Программа простая, но даёт понимание важной математической операции, которая используется в графике, машинном обучении и многих других областях.
